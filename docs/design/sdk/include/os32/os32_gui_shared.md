### T4. ハンドルと所有者

- すべての ID は `index:16 | generation:16`。破棄後の再利用で generation が進み、古い ID は
  `ERR_STALE` で弾く。0 は無効。

### T5. バージョン

- SHM ヘッダの `proto_version`。WM は自分の版より新しい要求を `ERR_VERSION` で返す。
- op 番号・イベント種別・構造体は**末尾追記のみ**。

### T7. エラー

戻り値は `i32`: `>= 0` 成功 (件数やハンドル)、`< 0` は `OS32_ERR_*` の流儀で
`ERR_STALE` / `ERR_VERSION` / `ERR_FULL` / `ERR_ARG`
GetLastError は作らない。

> [要確認] 元文の ERR_ARG に対応する現行の共有エラー名は OS32_ERR_INVAL (sdk/include/os32/os32_kapi_shared.h)。

- 上限 16 (既存 `MAX_WINDOWS`)。flags は既存 `GUI_WF_*` を継承。

### U2. イベント (型付き、16B 固定) — 2026-09-05 に配置を確定

全種別を**共通ヘッダ 8B + ペイロード 8B** に揃える

C (`os32_gui_shared.h`) と Rust (`proto.rs`) は**大きさ (16)
と各フィールドのオフセット**を両方 static assert し、

共通ヘッダ (オフセット 0〜7): `kind: u8` (0) / `sub: u8` (1、種別ごとの小さな値) /
`serial: u16` (2、入力系のみ。他は 0) / `window: u32` (4、**完全な WindowId = index:16 |
generation:16**)。古いイベントは generation が合わないのでクライアントが捨てる。index の
再利用に制約は無い。

| 種別 | `sub` | ペイロード (オフセット 8〜15) | 備考 |
|---|---|---|---|
| `Paint` | 0 | `rect: {x,y,w,h: i16}` (8〜15) | G4。導出型 |
| `Configure` | 0 | `rect` (8〜15) | 位置・大きさが確定した。導出型 |

- **`Key` は PC-98 スキャンコードをそのまま運ぶ**: `scan: u8` (= `KEY_*`)、`ch: u8`

  `down: bool`。スキャンコードは実機の定義なので将来も変わらず、ASCII の無いキーも表せる。
