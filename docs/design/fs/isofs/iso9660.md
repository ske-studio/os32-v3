# iso9660.c / iso9660.h — ISO 読取りとキャッシュの寿命

> 状態: **現行 (2026-10-31)**

`Iso9660Ctx` はパス 1 本、4 本の 2KiB セクタ LRU、32KiB の先読み窓を持つ。
窓は同じ媒体の物理 LBA 範囲 (`ra_lba/count/valid`) を表し、ファイルと
ディレクトリで共用する。確保できなければ従来の単セクタ経路で動く。
窓と ctx は umount で解放する。

ディレクトリ取得と LRU の実装は [iso9660_dir_read](iso9660_dir_read.md)。
検索・一覧の名前解析は本体に置き、レコード終端は `dir_size` を越えない。
一覧は既存の 2KiB ローカルコピーから callback を呼び、共有バッファへの
ポインタを callback 越しに保持しない。

## 落とし穴

- `iso_check_media` は媒体世代の変更と最後の媒体 I/O から 2 秒超でパス・LRU・窓を
  全失効する。ちょうど 2 秒は維持し、hit で最終 I/O 時刻を延ばさない。
- 検索とファイル読みは既存の入口・結果で世代を比較し、最大 2 試行。
  一覧は取得直後と各 callback 直後で比較し、変化したら `VFS_ERR_IO`。
  既に通知したエントリは巻き戻せないため一覧を自動再開しない。
- 未検知の交換をキャッシュだけで判定する仕組みは持たない。
  **CD を交換したら umount/mount** する。書込み操作はすべて拒否する。
