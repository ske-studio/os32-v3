# iso9660_dir_record.inc — ディレクトリレコード位置計算

> 状態: **現行 (2026-11-01)**

`iso_dir_record_length` は検索と一覧の共通部分。現在のセクタと走査位置から
レコード長を返す。正の値なら呼出し元がそのレコードを処理する。
ゼロ長パディングとセクタ境界をまたぐレコードでは位置を次のセクタへ進めて
0 を返し、呼出し元が `continue` する。ディレクトリの残量を越える非ゼロ長は
位置を変えず -1 を返し、呼出し元が `break` する。

## 落とし穴

- 判定順は従来どおりゼロ長、ディレクトリ残量、セクタ境界。新たな検証は加えない。
- セクタ取得・名前解析・通常のレコード長ぶんの位置更新は各呼出し元に残す。
- 検索はキャッシュを直接参照し、一覧はローカルコピーを参照する。
  まとめ読み、callback とその前後の媒体世代検査には関与しない。
