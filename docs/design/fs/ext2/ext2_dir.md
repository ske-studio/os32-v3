# fs/ext2/ext2_dir.c — ext2 ディレクトリ操作

> 状態: **現行 (2026-10-31)**

ディレクトリの列挙、名前の検査、項目の作成と削除を行う。
rename の更新順序も管理する。

## 落とし穴

- **列挙中の再入**: callback から FS に書くと共有 scratch が変わり、後続の一覧が壊れる。
  走査ブロックを私有バッファに読み、そこから callback を呼ぶ (`fs/ext2/ext2_dir.c:7`, `fs/ext2/ext2_dir.c:31`)。
  呼び手も名前を集めてから FS を操作する。FatFs と HostDrv の同型経路は未監査。
  この再入の直接試験は未確認。

- **ディレクトリ rename の順序**: 失敗途中で二つの名前が同じディレクトリを指すと、片方の削除で残りが解放済み inode を指しうる。
  ディレクトリは旧名を先に外し、新名を付ける (`fs/ext2/ext2_dir.c:766`)。
  I/O 失敗を不存在に読み替えない。失敗経路の回帰は `tools/tests/test_b8_open.py`。

- **不正な名前**: 空名は列挙時に読み飛ばされるため、OS32 で読めても媒体が正しいとは限らない (`fs/ext2/ext2_dir.c:43`)。
  空・`.`・`..`・長すぎる名前・`/` を含む名前は書込み前に拒否する (`fs/ext2/ext2_dir.c:74`)。
  `make check-ext2-empty-name-host` と `tools/tests/test_b8_open.py` はホスト像を検査する。
  実インストール像も別途 `e2fsck -fn` で検査する。
