# fs/ext2/ext2_inode_write_bmap.inc — 書込み用の間接表

> 状態: **現行 (2026-10-31)**

[共有契約](ext2_priv.md) の上位1枚・単間接/下位2枚を保持する。get と set は
同じ physical キーを使う。新しい表は全0で準備し、親の0項目への追加位置を
記録する。予約したdata/表の i_blocks はRAMで加算する。

昇順の最大64データ窓では下位表は最大2枚。次の窓ではclean枠だけを置換する。
bitmap確定後にdirty下位表2枠、上位表の順に書く。変更のない上位表は書かない。
trim は成功prefix以後の新規dataと追加参照を外し、新規の空表を子から親へ
除去する。既存根・既存参照・前窓の公開済み予約は取り消さない。

## 落とし穴

表の公開前にdataとbitmapを完了させる。逆順では使用中inodeから未割当dataを
辿れてしまう。dirty表を追い出して先に公開しない。直接→単間接→二重間接、
下位表切替、途中の512B像は `tools/tests/test_ext2_write_batch.py` で検証する。
