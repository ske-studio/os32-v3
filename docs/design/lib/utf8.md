# lib/utf8.c — UTF-8 の走査とデコード

> 状態: **現行 (2026-10-31)**

UTF-8 の文字境界、デコード、文字列の走査を提供する。
バイト数と文字数を別々に扱う。

## 落とし穴

- 日本語の文字数や表示桁数をそのままバッファのバイト数にすると、溢れや途中切断が起きる。
  UTF-8 は文字により長さが異なる (`lib/utf8.c:36`)。バイト容量、コードポイント数、
  表示桁数を区別し、必要な終端分も確保する。切詰めは続きバイトの途中を避ける
  (`lib/utf8.c:244`)。全 Unicode を一律 3 バイトと見なさない。
  この切詰め規則そのものの専用試験はここでは確認できていない。

## 内部設計と契約 (D1)

**KCG を予備に落としても表は消えない** (TVRAM コンソールと FEP の TVRAM 描画が JIS)。
