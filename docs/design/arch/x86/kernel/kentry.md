## 落とし穴

- **BSS の初期化**: ベアメタルでは CRT が BSS を消さず、ゼロ初期値の大域変数が不定になる。
  リンカの `__bss_start` から `__bss_end` までを C に入る前にゼロにする (`arch/x86/kernel/kentry.asm:18`)。
  起動時の初期化順を変える場合もこの契約を保つ。直接の BSS 初期化試験は未確認。
