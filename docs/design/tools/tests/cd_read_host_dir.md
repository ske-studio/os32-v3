# cd_read_host_dir.inc — ディレクトリ取得のホスト試験

> 状態: **現行 (2026-10-31)**

[共通 fixture](cd_read_host.md) 上で製品 ISO/ATAPI を動かす。
Device の要求列と READ(10) の列は別々に記録し、LBA・個数・全セクタ数を照合する。

- 0/1/4/16/17/32 セクタ、半端末尾、ゼロ長パディング、先頭／末尾発見・未発見。
- volume 終端と extent 終端を越えない要求、サイズ外レコードの非公開。
- LRU 優先と訪問済みセクタの保持、窓あり／なしでの名前・属性・サイズ一致。
- callback 内のファイル読出し・再帰一覧。親の窓競合後は単セクタに戻り、
  16 セクタ走査で 16 要求・31 セクタを越えない（callback の I/O を除く）。
- 補充途中の不良、必要セクタ自身の不良、失敗バッファの毒データ非公開、
  無関係な LRU・パスの保持、下位の単セクタ再試行数。
- 既知の世代変更前後、既存の補充途中 UA・callback UA、2 秒ちょうど／超過・周回。

既存 `list_swap` の pending UA は 17 セクタ目の窓境界で検知させる。
媒体交換の実機受入は PM が umount/mount の契約で行う。
