# cd_read_host_pio.inc — L2 の PIO 保存試験

> 状態: **現行 (2026-10-31)**

[共通 fixture](cd_read_host.md) で製品 `atapi_packet_read` を呼ぶ。
1/7/8/9/2048/32768 バイト、DRQ 分割、容量 0/1 バイトを含む短い／過剰応答、
非整列先頭を組み合わせ、CDB 12 バイトと全入力ワード列、バイト列、actual、
診断、全ガード領域を照合する。途中 DRQ エラーも部分診断と actual を照合する。

同一試験を L2 基点ソースの一時ツリーにも適用し、分離前後の契約を比較する。
製品アルゴリズムは試験に複製せず、ポートの原語だけ模型へ置換する。
実機の PIO タイミングはこの試験だけでは保証しない。
