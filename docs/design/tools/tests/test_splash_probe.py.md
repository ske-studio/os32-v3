# tools/tests/test_splash_probe.py — プローブ試験と変異

状態: **現行 (2026-11-01)**。

実際の診断プローブと再生器、独立した模型を隔離コピーし i386/qemu で実行する。
CHECK は実際に読む/組む入力だけを宣言し、LC-B の模型へ依存しない。
模様・受信・フレーム時刻・測定中出力に加え、Q/C/W の費用分離、Q の比較/計数、
8周期/4型分類、V/H の区間、累積 J、D を含む J_max、負の余裕と未確認予算の
採用を変異で壊し、コンパイル成功後の実行時 RED を要求する。
短い費用測定のIF=0除去、IF=1値の上限への混入、整数比のµsへの丸め、
Hの連続INへの時計挿入、途中周期の混入、high比率/B上下限/2Hの破壊も変異で検査する。
begin前・後のBIOSの写し経由の読みを、それぞれ直接のP2V_IO読みに戻す変異を持つ。
両変異とも目印が一意で、コンパイル後にページ0の直接読取拒否で実行時REDとなる。
