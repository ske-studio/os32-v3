# tools/tests/splash_probe_host.c — プローブの試験模型

状態: **現行 (2026-11-01)**。

独立した走査時計を IN、時計、各 OUT で別々に進め、実際の probe と現行再生器を
組んで qemu で実行する。IN はサンプル時刻と戻り時刻を分ける。
IN=1/5/8、時計=1/5/8、OUT=1/2µs の直積で Q/C/W が与えた費用に一致することを検査。
24/31k×非表示全体/VS の4型を、実機参照幅/NP21/W相当の広幅で動かす。
V/H の真の辺時刻が測定区間に入ること、32 VS/64 H周期、初期色、模様/副尺、
フレーム記録、連番受信、測定後だけの出力を検査する。

二つの IRQ を別々に注入し J の累積28µsを検査する。J_max の二入口/一入口/空、
負の余裕、IF=0≤2Hと復元後1H開放、未知の高幅/周期不一致、初期色中の IRQ 超過、
H停止/時計停止の有限終了を確認する。実機費用や LC-B の再生成功の代用にはしない。
