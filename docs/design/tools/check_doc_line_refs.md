# tools/check_doc_line_refs.py — 文書の行番号つきの参照の戻り止め

> 状態: **現行 (2026-11-17)** — ユーザー決定 2026-11-17 (行番号つきの参照を禁止する)。決まりの本文は [POLICY_DEV §9](../../POLICY_DEV.md)。
ソース: `tools/check_doc_line_refs.py`・`tools/doc_line_refs_baseline.json`・`tools/tests/test_doc_line_refs.py`

## 目的

リポジトリの文書が、このリポジトリのソースを `パス:行番号` で指すと、ソースが動くたびに黙ってずれる (置き場の移動の道具はパスだけを新しくして、行番号は古いまま残す)。現行の文書に行番号つきの参照は 1 件も無く、新しく書くと検査が落ちる。

## 数える物

| 項目 | 決まり |
|---|---|
| 対象の文書 | 追跡されている `.md`。`docs/archive/`・`docs/hw/` は除く (サブモジュールの中は追跡の一覧に出ない) |
| 数える参照 | `<パス>:<行>` で、`<パス>` がディレクトリ付きで、このリポジトリに追跡されているファイルと一致する物。範囲や列挙 (`:12-30`・`:12,40`) は 1 件 |
| 木の記法 | `O/kernel/a.c:12` のような 1 文字の頭は落として照らす (このリポジトリを指す記法として使われている) |
| 数えない物 | 外部の手本のパス (追跡されていない)、ファイル名だけの形 (`kernel.c:521`。外部の同名のファイルと区別できない)、行番号の無いパス |

## 基準

`tools/doc_line_refs_baseline.json` は `{文書: 件数}` で、今は空 (`{}`)。基準に無い文書は 0 件が基準なので、どの文書でも 1 件あれば落ちる。

基準は増やさない (行番号を書く理由が出た時は、パスと関数・マクロ・節の名前で指す)。

## 検査

| 検査 | 中身 |
|---|---|
| `docs-line-refs` | 実物の木を数えて基準と照らす。CI の check (static-check) と build (checks) で回る |
| `docs-line-refs-host` | 偽の木での単体試験 4 本と変異 10 本 (数える条件・除く置き場・基準との比較の両方向・終了コード) |

## 範囲の外

ファイル名だけの行番号つきの参照 (`kernel.c` の形) は数えていない。直す時は、パスの付いた形と一緒に名前の参照へ直す。
