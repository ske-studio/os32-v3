# tools/check_archive_refs.py — アーカイブを指す参照の戻り止め

> 状態: **現行 (2026-11-18)** — ユーザー指示 2026-11-18 (増加だけ止める・[D4] を実態に合わせて書き分ける)。決まりの本文は [CONSTRAINTS](../../CONSTRAINTS.md) の [D4]。
ソース: `tools/check_archive_refs.py`・`tools/archive_refs_baseline.json`・`tools/tests/test_archive_refs.py`

## 目的

`docs/archive/` の文書は過去の記録で、作業と試験の根拠にしない ([D4])。ところが票をアーカイブへ移す道具
(`tools/move_docs.py`) は参照を追従させるので、現行の票を指していた試験の覚えやソースの註が、票ごと
アーカイブを指す形になって残っている。これを 2 つに分ける:

- **来歴の記録** (この実装はどの票で決めたか): 残してよい。新しく足さない。
- **契約の出所** (試験の期待がどこから来たか): 現行の文書 (`docs/design/<ソースと同じパス>.md`・仕様) を指す。
  アーカイブにしか無い契約は、その領域を触る時に現行の文書へ要約して引き先を替える。

この検査は、アーカイブを指す参照の件数が増えた時に落ちる。

## 数える物

| 項目 | 決まり |
|---|---|
| 対象のファイル | 追跡されているファイルのうち 3 つの群: 試験の覚え `tools/tests/*_tdd.md`、ソース (`.c` `.h` `.inc` `.asm` `.S`)、`tools/` の下の `.py` |
| 数える参照 | `docs/archive/<…>/<名>.<拡張子>` で、このリポジトリに追跡されているファイルと一致する物 |
| 数えない物 | `docs/archive/README.md` (アーカイブの運用、現行の文書)、実在しないパス (試験の作り物)、置き場だけの言及 (`docs/archive/` で終わる物) |
| 対象の外 | 現行の文書 (`docs/`) からアーカイブへのリンクは `check-docs-tree` が 0 件を見る。検査の宣言の basis は `tools/checks/run.py --lint` が止める |

## 基準

`tools/archive_refs_baseline.json` は `{ファイル: 件数}`。ファイルごとに、基準より多くても少なくても落ちる。
基準に無いファイルは 0 件が基準なので、新しいファイルに 1 件書けば落ちる。

| 起きた事 | する事 |
|---|---|
| 新しく書いて増えた | 現行の文書を指す形に直す |
| 契約を現行の文書へ要約して、引き先を替えて減った | `python3 tools/check_archive_refs.py --write-baseline` |
| 票を移した追従で、来歴の註が増えた | 試験の覚えの出所は移す前に付け替える。残るソースの註の分は、同じ変更で `--write-baseline` |

作った時の件数 (2026-11-18): 260 ファイル・362 件 (試験の覚え 76 本 121 件、ソース 114 本 128 件、道具の Python 70 本 113 件)。

## 検査

| 検査 | 中身 |
|---|---|
| `archive-refs` | 実物の木を数えて基準と照らす。CI の check (static-check) と build (checks) で回る |
| `archive-refs-host` | 偽の木での単体試験 5 本と変異 12 本 (3 つの群の境目・実在の確かめ・運用の README の除外・基準との比較の両方向・終了コード) |

## 範囲の外

ソースの註は直さない (契約のヘッダは全文のハッシュが ABI の世代に入るので、註の 1 行で生成物が変わる)。
パスを消すだけの直しはしない (出所の手がかりが消えるだけで、契約が現行に無い事は変わらない)。
