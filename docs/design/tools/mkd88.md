# tools/mkd88.py — 2HD D88 イメージ生成

> 状態: **現行 (2026-10-31)**

固定ジオメトリの生イメージから D88 トラックとセクタを作る。

## 落とし穴

- **1.44MB の rpm**: この生成器は 8 セクタ×1024 バイトの 2HD 用で、ヘッダの種別は 0x20 (`tools/mkd88.py:22`, `:54`)。
  セクタの予約領域もゼロ (`:78`) なので、1.44MB 用の種別 0x21 と各セクタの rpm フラグ 1 を生成しない。
  この形式のまま 1.44MB D88 として使うと読みを拒否されうる。1,474,560 バイトの生イメージを選ぶか、両方のフィールドを対応させて検証する。
