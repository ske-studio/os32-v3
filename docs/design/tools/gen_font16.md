# tools/gen_font16.py — 16px ビットマップフォント生成

> 状態: **現行 (2026-10-31)**

入力フォントから ANK と漢字のセルを生成し、プレビューを出す。

## 落とし穴

- **セル幅とベースライン**: プロポーショナルの広い字をそのまま 8px に置くと左右が切れ、字ごとの ink box 基準では行が揺れる。
  `tools/gen_font16.py:107` はベースライン基準で描き、幅を超える字だけ横に縮める。ANK と漢字の baseline は 12 / 13 (`:71`)。
  `--preview` (`:305`) の等倍表示で判読性を確かめ、細い漢字の画線が消えないフォントを選ぶ。
