# drivers/ata/ide_request.inc — 要求検査と分割

> 状態: **現行 (2026-10-31)**

公開の単数・複数・CHS 単数入口を持つ。ドライブの既存正規化を保ち、
複数 API は要求全体を `ide_addr_range_ok` で発行前に検査する。
存在・幾何を確認した count=0 は成功し、番地・コマンドを書かない。

LBA28 は残数と最大 256 の小さい方を 1 コマンドにする。
CHS は `ide_addr_mode` の現在／既定 spt を使い、トラック末尾まででさらに区切る。
各チャンクの開始番地は `ide_addr_make` で作り直す。
PIO のため DMA の 64KiB 境界では分割しない。

SASI 256B 媒体は従来どおり count=1、512B 転送、要求内の LBA+1 を反復する。
FatFs 自身が行う LBA+2 の要求列の意味を変更しない。
I/O が失敗したら後続チャンクを発行せず、その負のエラーを返す。

追加常駐領域・ヒープは 0B。開始番地・残数・ポインタは呼出し内で破棄する。
転送手順は [ide_pio](ide_pio.md)、検出状態は `ide`（ide.md）。

## 落とし穴

容量超過や LBA28 上限超過を分割によって救済しない。
全範囲が不正なら、先頭の有効区間にも 1 コマンドも出さない。
