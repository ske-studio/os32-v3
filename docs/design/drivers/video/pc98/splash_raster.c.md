# splash_raster.c — 判定とパレット再生

状態: **現行 (2026-11-01)**。ソース: `drivers/video/pc98/splash_raster.c`。

09A8h は PEGC_HSYNC_READ_HF の D0 だけを使う。新しいVSYNC立上り9回から8周期を
64bit交差積で±1%照合する。8回の高期間平均が非表示全体幅±1行なら active0=0、
VS幅±1行なら active0=VBP。どちらでもなければ dynamic_ok=0。判定値を周期そのもの
には使わない。時計は sys_time_now、各待ちは100msまたは局所期限と有限反復で止まる。
期限ちょうどで辺が無い場合も終了し、次のポーリングまで禁止区間を延長しない。
初回判定の入口IF=0ではcheckedを立てずに戻り、次のIF=1の利用で再試行する。

table はline=0をVSYNC入りに初期色として設定し、残りは立下りからの絶対行位置へ
配置する。立下りの約1行前から捕捉だけを保護し、保護直後のVSYNCが既に0なら
IFを戻してフレームを破棄する。1から0への変化だけを捕捉し、予測より半行以上遅れた場合も
フレームを破棄して次回回復する。高期間はµsへ切り上げ、時計の量子化で捕捉窓を
早く閉じないようにする。イベントは目標1行前から新しいHBLANK辺と4 OUTだけを
保護する。各保護区間後は切り上げ1行分以上IF=1へ戻す。遅延時はこの窓を優先し、
同indexの期限切れ値を最新値に畳み、画面外の未適用件を捨てる。lateは各予定件を
一度だけ数え、停止条件にはしない。入口IF=0の動的表は何も書かずに戻る。

固定色は動的判定に依存せず、新しいVSYNCで16色を設定する。期限までの待機、
VRAM転送、gfx寿命フックの接続は呼出側の後続段の責任。FS・VRAMには触れない。

根拠は確定設計 RASTER_SPLASH_DESIGN §2/§5。メーカー照合はNEC PC-9800 Technical
Databook Hardware (1993) p.351（PM照合、24kHz）。31kHzの位相・I/O予算は段0実測の
関門であり、ホスト模型の合格で置き換えない。同期辺・番号/G/R/Bの参考は
[FreeBSD releng/10.4 gdc.c:655,685,831](https://github.com/freebsd/freebsd-src/blob/releng/10.4/sys/pc98/cbus/gdc.c#L655)
（BSD 3条項）。描画コマンドや実装構造は取り込まない。
