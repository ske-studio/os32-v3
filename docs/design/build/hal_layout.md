# HAL の契約と実装の配置

> 状態: **現行 (2026-11-27)** — A1 の D-4 と U17 に基づく配置。

## ファイル単位の判断

配置はファイル単位で決める。HAL と装置をまたぐファイルは、操作表の名前だけで判断せず、登録元・委譲先・呼び出し側を調べる。たとえば `sys/hal/gfx/gfx_core.c` の `gfx_mode_fits` は、PC-98 の表示面を特別扱いする。この条件を提供側に渡すにはインターフェースの変更が要る。

| 仕様 §4 の責任 | 配置と境界の例 |
|---|---|
| HAL 契約・型・共通処理・振り分け | `sys/hal/<分野>/`。入力の `InputOps` は契約、イベントリングは共通処理、`input_getkey` は登録先への振り分け。音源のストリーム状態もここで持つ。 |
| CPU 固有バックエンド | `sys/arch/<CPU>/`。ページ表の走査や RDTSC による計時は CPU 側が提供し、共通の照合・集計には結果を返す。 |
| 機種固有バックエンド | `sys/platform/<機種>/`。PC-98 の表示経路と tick の接続、PowerMac の起動時入力の登録など、機種の配線と初期化順を持つ。 |
| デバイス固有バックエンド | `sys/dev/<装置>/`。GeForce の ROM 命令や CS4231 のレジスタ操作を持つ。装置内部の型・操作表・診断もその装置に属する。 |

HAL の利用者も調査対象に含む。受信後のプロトコル選別は `sys/net/`、IME や画面所有者の規則は入力・カーネル側が持つ。GeForce は `sys/dev/video/geforce/` に置き、表示計算や初期化命令の下位ディレクトリを保って同名ファイルの衝突を避ける。

## P3 の移動と P8 の分割

624 ファイルのうち、570 は中身の分割を要しない。このうち P3 で `sys/hal/` へ丸ごと移せるのは 101（契約 21、型 4、共通処理 59、振り分け 17）。ほかの移設先は各所有者の配置に従う。P3 ではパス参照を追従し、P2-1 で生成物の一致を確かめる。

残る 54 本も P3 で兄弟と同じ行き先へ丸ごと移す。このうち 12 本は sys/hal/ に入る。中身の分割は P8 の候補にした。分割では次の責任を分ける。うち 18 は分割後に一部を `sys/hal/` に置く候補で、分割不要の 101 には含めない。たとえば `keymap.h` は共通の型を HAL に、PC-98 専用の登録宣言を機種側に分ける。`dev.c` は共通の媒体転送と FDD・IDE の実操作を分ける。

| 分野 | 分割時の判断 |
|---|---|
| ブロックと FS | 共通側が転送範囲・キャッシュを管理し、FDD・IDE の実操作、物理セクタ長・媒体世代はアダプタが提供する。 |
| 入力とネットワーク | 共通側がイベント・マップ・受信能力を扱い、登録側がキー形式、機種の既定値、具体的な NIC と tick の配線を渡す。 |
| 表示 | HAL が列挙・モード・描画面を管理し、バックエンドがコネクタ、表示形式、機種固有のページ順・経路を決める。写像属性・ページ表の走査と復元は CPU が提供する。 |
| 起動・実行・診断 | 共通側が必要とするのは待機、終了通知、監査結果や時刻。具体的な装置、ページ切替、カウンタを選ぶ処理は提供側が持つ。KAPI の委譲を変える時は生成入力で行い、公開 ABI を保つ。 |

P8 候補の元になったファイルごとの判断は移行時の SHA `64aff86c9` に残る。上記は U17 が分割を先送りした際の境界で、P4 以後の修正を含む現在の残件数を示す数字ではない。

## D-4 で決まった配置

音・入力のファイルは、装置を差し替えても使える契約と処理を分野別にまとめる。`sound/hal/` のストリーム管理、能力照会、旧 PCM API 変換を `sys/hal/sound/` に置く。`input/hal/` のデバイス登録、イベント状態、キー変換、ポインタ操作を `sys/hal/input/` に置く。入力の文脈・方針、IME のゲート、割り込み要求を扱う6ファイルは `sys/input/` に置く。

`include/*_contract.h` は同じ基準で選ぶ。P3 で丸ごと移す契約ヘッダは次の3本。

| 契約ヘッダ | 行き先 | 共通の呼び出し口 |
|---|---|---|
| `gfx_present_contract.h` | `sys/hal/gfx/` | planar 転送と表示後診断を機種が提供する契約 |
| `mouse_pointer_contract.h` | `sys/hal/input/` | ポインタ状態を採取するバックエンドの登録 |
| `snd_wake_contract.h` | `sys/hal/sound/` | 音源の通知をクロックに登録する契約 |

この3本は P0-6 の対象外で、A1 で追加した。D-4 を含む P3 の HAL 移動は 116 本（分割不要 104、P8 対象 12）。P8 では ext2_medium_contract.h の媒体操作表と登録口を sys/hal/block/ に置き、ext2_medium_ide_ops と ext2_medium_loop_ops の宣言は sys/platform/pc98/boot.c が参照する各アダプタの登録用ヘッダに分ける。残りの契約ヘッダは現行の利用者と提供者の境界を保って P1-1 で配置する。たとえば `av_contract.h` は V86 と KAPI 入口も宣言し、`pcm_contract.h` は CS4231 系の版と tick 配線も規定する。いずれもファイル丸ごとの HAL 移設から外す。
