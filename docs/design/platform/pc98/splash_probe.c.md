# platform/pc98/splash_probe.c — 診断ビルドの計測

状態: **現行 (2026-11-01)**。

`kernel-splash-diag` のみが SPLASH_RASTER_DIAG を定義し、別 BUILD_OUT のオブジェクト・map・像を組む。通常の kernel/all は probe をリンクしない。begin 前には09A8hと054Chを記録し、begin 後に比較する。054Chは既存PEGC定数を添字に `v86_bios_real_lowmem()` の起動時の写しから読み、判定には使わない。ページ0はNULL保護で未写像のため直接読まない。前後とも同じ不変のBIOS値であり、beginによる変化は09A8hで観測する。

RAMに32 VSYNC周期と両辺/テキスト状態、64 HBLANK周期/幅、時計128回、空ループと1/4/8色・8/16 OUT・初期16色、32フレームのIF最大/合計・late/drop/未適用・tickを採る。32周期のmin/median/p99/max、絶対予定/開始/終了は測定後にシリアルへ出す。時計異常・有限ポーリング・記録溢れはerrorsとして扱い、共通cleanupへ戻る。

模様は中央パレット1、16行目盛、上下枠、16色タイル、8行縞の−4〜+4副尺。4行境界を9回1行ずつずらし、その後は固定の4行帯を測る。無負荷/受信負荷は同じ診断像をPMが別々に起動する。負荷入力は0始まりの連続little endian u32列。各フレーム後に既存RXリングを読み、断絶/端数とOE/FE/PE/overflow差を記録する。欠番の原因や受信ゼロを負荷合格とは判定しない。

既存120µs版との速度/転送比較はPMが基点の像と実施する。診断内に旧再生を復活させない。時計読出しの費用・1µs量子化と診断追加の観測負荷を含むので、実機の予算採用はPMの観測ゲート。根拠はNEC Technical Databook Hardware (1993) p.350–351（PM取得済み、31k表は未掲載）と [FreeBSD gdc.c](https://github.com/freebsd/freebsd-src/blob/releng/10.4/sys/pc98/cbus/gdc.c#L655) の同期/パレットI/Oだけ。描画コマンドは使わない。

LC-A の追加測定は RAM 固定配列で持ち、既存の走査後出力にまとめる。
Q は時計を内側に入れない IN の比較/計数ループ、C は連続した時計、
W は4 OUT を別々に計る。IF=0 の最大8回の束を64回測り、両端の時計込みで
2Hに収まるよう、単発の予備測定から束の回数を半減する。各復元後は1H以上開放する。
平均は total_us/samples、上限は束の平均の最大 upper_num_us/upper_samples。
C の下側の束平均を Q/W の端点時計から引き、量子1µsも束の分母で割る。
Q/W の分母には C の分母も掛け、C の量子を丸ごと1µsとして再計上しない。
upper_us は粗待ち専用の切上げ値で、Q/C/W の予算は整数比を共通分母へ切り上げる。
同じ束を IF=1 でも測り、割込みを含む if1_total_us/if1_max_batch_us として別記する。
実機値は観測上限であり任意の実行に対する証明にはしない。
従来の空ループ・単一 OUT の生値も残す。

先頭8 V周期を公称±1%で照合し、高幅合計を±1行で分類する。
wave=1/2 は24kの非表示全体/VS、3/4 は31k、0 は不一致。
同じ IN の V/H を時計で挟み、F と次の新しい H の区間を記録する。
同時変化は `phase_ambiguous=1`。開始時 high を新しい H と数えない。
H幅は両端の時計込みで最大2Hの IF=0 区間へ分け、区間内は時計を挟まず IN を連続する。
区間内で完結した立上り→次の立上り64周期だけの high/全サンプル数を集め、
その比率×8フレーム由来のHでBを求める。区間間の開放時間や途中の周期は比率に含めない。
Bの上下限はHの上下限で換算した比率に±Qを加え、時計Cを幅から引かない。
hperiod_us は周期内サンプル数×Qの束平均、hwidth_observed_us は周期ごとの比率×H。
NP21/W の広い bit6 を物理的な B と同一視せず、極性の自動反転も行わない。

診断の入口調査はパレットを書かず、4行差分99件の S_j/S_(j+1)、r、D、
J_max(y)、起点捕捉/初期色の余裕とその全体最小を分母付きで記録する。
入口の事前時計→irq_save→再時計→IN→復元を別に測り、失敗事前検査の費用も
D に記録する。各復元後は1H以上開放し、観測費用が2Hに収まる場合だけ測る。
この診断手順の IF=0 最大/合計は従来再生の IF 統計と分けて出す。
粗待ち中の各時計差から C の範囲を除いた残差の累積を J 区間として記録し、
入口の前後時計も含める。非IRQ処理の揺らぎも残るため上側は保守的な観測値。
無負荷/受信負荷は別起動で、wait_begin/planned/entered/end と RX 語数を対応させる。

この S/D は診断手順の候補値。LC-B の分岐/再試行/中継・起点の番号一意性と
実機副尺の照合を経ていないため `qualified=0` とし、dynamic_ok を変更しない。
常用再生器への採用値を捏造しない。負の初期色余裕も符号付きで出し、
非表示全体型は可視開始に加え F 捕捉の最早入口までの余裕を差し引く。
VS型の16色は F 後の VBP で測る。初期色 IRQ 超過は負の余裕として観測できる。
