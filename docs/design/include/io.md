# include/io.h — I/O と CPU 待機の共通契約

> 状態: **現行 (2026-10-31)**

ポートアクセス、短い I/O ウェイト、CPU 待機の入口を定義する。
実装はアーキテクチャとプラットフォームが提供する。

## 落とし穴

- `io_wait` は時間待ちの汎用タイマーではなく、PC-98 ではウェイトポートへの書込み
  (`platform/pc98/platform_io.h:59`)。NP21/W で大量に連打した後の FD 読取りが
  古いデータを返した観測があり、原因は未特定、実機再現も未確認である。
  tick の変化をただ待つループで連打せず、適切な CPU 待機を使う。
  `_idle` の割込み許可と待機は不可分という契約も守る (`include/io.h:115`)。
  この大量連打の現象を守る専用試験は確認できていない。
