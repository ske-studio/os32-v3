### §3-2 ディスクセクタ配置 (FAT12)

ブートFDは FAT12 ファイルシステム (`tools/mkfat12.py` で生成)。
カーネル等はローセクタ配置ではなく **FAT12 上のファイル** として格納される。
ゲスト側のマウントは FatFs (`fs/fatfs/`) が担当する (自作 fat12 ドライバは廃止済み)。

```
LBA     用途
─────────────────────────────────────────────
0       IPL (boot_fat.bin, 1024B) — FAT12を解釈し /LOADER.BIN をロード
1-2     FAT1 (2セクタ)
3-4     FAT2 (2セクタ)
5-10    ルートディレクトリ (192エントリ, 6セクタ)
11-1231 データ領域 (クラスタ2〜, 1024B/クラスタ)
```

主要ファイル (`build/image.mk` の `images/os32_boot.d88` ターゲットが配置)。
**中身は CD の BOOT + MINIMAL と同じ集合**で、`build/packages.yaml` の `fd:` から
`tools/mkpkg.py --fd-args` が作る (FD だけの物と 8.3 の置き場所は
[08_build.md の「起動 FD と MINIMAL」](08_build.md#起動-fd-と-minimal)):

| ファイル | 内容 |
|---------|------|
| `/LOADER.BIN` | 第2ステージローダー (`loader_fat_new.bin`) |
| `/VMKRNL.LZ4` | LZ4圧縮カーネルイメージ (kernel.bin + sqlite.bin) |
| `/sys/shell.bin`, `/sys/unicode.bin` | シェル・Unicodeテーブル |
| `/bin/*.bin` | 直す道具 less / grep / hexdump / cfg (配備マニフェストのタグ `base`) |
| `/sbin/install.bin`, `/sbin/cdinst.bin` | HDD/CDインストーラ |
| `/sbin/hsync.bin` | 残りを `/host` (HostDrv) から取ってくる |
```
ブート: IPL → /LOADER.BIN (0000:8000) → /VMKRNL.LZ4 展開 → kernel_main
```

### §3-4 HDD (IDE) ディスク仕様

#### NHDイメージのジオメトリ
- **シリンダ数**: 3011
- **ヘッド数**: 8
- **セクタ/トラック**: 17
- **セクタサイズ**: 512バイト
- **総容量**: 約200MB (詳細は [NHD_FORMAT.md](NHD_FORMAT.md) を参照)

#### セクタレイアウト
```
LBA        内容                          サイズ
──────────────────────────────────────────────
  0        IPL (boot_hdd.bin)            512B (1セクタ)
  1        パーティションテーブル         512B (1セクタ)
  2-17     第2ステージローダー            8KB (16セクタ, MAX_LOADER_SECTORS)
 18-261    カーネル直接配置領域           最大122KB (レガシー/フォールバック用)
 262-1631  sqlite.bin直接配置領域+予約    シリンダ1〜11
──────────────────────────────────────────────
 1632      ext2パーティション開始         シリンダ12から
──────────────────────────────────────────────
```
**注意:**
- 通常ブートは ext2 内の `/VMKRNL.LZ4` (LZ4圧縮カーネル) を第2ステージローダーが展開する方式。
  LBA 18/262 の直接配置はレガシー経路で、これを書き込んでいた `nhd_deploy.py write-kernel`
  サブコマンドは削除済み。領域自体は互換のため確保されたままになっている。
- 直接配置を使う場合、カーネルが LBA 262 (`sqlite.bin` 領域) に侵食しないよう
  カーネルサイズは最大 (262-18)×512 = **122KB** に制限される
  (現在の kernel.bin は約147KB で、この上限を既に超えている。通常ブートは
   ext2 上の LZ4 圧縮カーネルを使うため支障はないが、レガシー経路は
   もう使えない)。

#### パーティションテーブル (LBA 1)
PC-98形式の32バイト/エントリを使用 (`nhd_deploy.py update_partition_table()`):
- オフセット 0: ブータブルフラグ (`0x80`)
- オフセット 1: システムタイプ (`0xE2` = ext2)
- オフセット 6: 開始セクタ (`0`)
- オフセット 7: 開始ヘッド (`0`)
- オフセット 8-9: 開始シリンダ (`12` = LBA 1632 / 136)

### §3-5 INT 1Bh ディスクI/O (HDD仕様)

フロッピーディスクの INT 1Bh とはパラメータの指定方法が**異なります**。

| パラメータ | 指定方法 | 備考 |
|-----------|---------|------|
| DA/UA | `80h` (固定) | SASI/IDE互換アドレス |
| BX | **転送バイト数** | 仕様書には「ブロック数」とあるが、実際には**バイト数を直接指定** (`BX=512`で1セクタ) |
| DL | **セクタ番号** | フロッピーと異なり、HDDでは **0から開始** する (`0〜16`) |
| CX | シリンダ番号 | 全16ビット (CL=下位, CH=上位) |
