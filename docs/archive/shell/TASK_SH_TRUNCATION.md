## 0. 目的

**シェルが入力を切り詰めたまま実行を続ける経路をすべて断つ。** 切り詰めたら実行せずに断る。

これは新機能ではなく**既存の不具合の修正**。`$?` の有無に関係なく今日のコードで起きる。
いちばん重いのは `if` の比較で、**条件が逆になって別の枝が走る**:

```
if "<256 文字以上で先頭 255 文字が同じ文字列 A>" == "<同 B>" rm -rf /data
```

`cmd_script.c` の `strip_quotes` が両方を 255 文字に切り詰めるので `A == B` が真になり、
**本来実行されない破壊的なコマンドが走る** (`cmd_script.c:349-357`、`cmd_if` の `v1[256]` / `v2[256]`)。

## 2. 方針

**「切り詰めたら実行しない」を 1 つの規則にする。**

1. 入力が上限を超えたと分かったら、**その場で赤字のエラーを 1 行出して、行全体を実行しない**。
   切り詰めた値で先へ進まない (比較・起動・登録・展開のいずれも)。
2. エラーの文言は「何が上限を超えたか」と「上限」を出す (例: `sh: argument too long (max 255)`)。
3. 上限そのものは**変えない** (バッファを増やす改修ではない)。上限は既に定数なので [C4] に従って参照する。
4. 履歴 (T14) は実行経路ではないので、**切れた行は履歴に入れない**。`hist_load` も切れた行を読み込まない。
5. `glob` の確保失敗 (T6) は行全体を断り、確保済みの文字列を解放する。
6. `filer` (T16) は収まらない名前を**表に載せず件数だけ報せる** (`sh_ls.inc` の作法に揃える)。
   `fl_path_join` は溢れたら断り、`ft_load` は読み切れなければ関連付け表を使わない。

### 2-1. スクリプトの中で断ったら、その先を実行しない (レビュー往復 1 blocker 1)

**断った行を捨てて次の行へ進むと、切り詰めを直したせいで本来走らないコマンドが走る。**

```
set A=<249 文字>
if $A$A == $A$A goto done      ← 展開後 498 文字。今は切り詰めて一致し goto done へ飛ぶ
rm -rf /data                    ← if を「実行しない」だけにすると、ここへ落ちる
:done
```

規則: **スクリプト実行中に行を断ったら `script_abort_flag` を立てて打ち切る** (`goto` のラベル無しと同じ扱い)。
組み込み handler は `void` のまま (`int` 化は [`TASK_EXIT_STATUS.md`](TASK_EXIT_STATUS.md) の範囲) なので、
**断ったことを表す印をグローバルに 1 本**持ち、`execute_command` の入口で消し、`script_exec` が
`execute_command` の後に見る。`if` / `time` 経由の入れ子 `execute_command` からも伝わること、
入れ子 `source` は `script_source_file` の戻り値で親に伝えることを実装の条件に入れる。

起動時の `/etc/profile` で断ったときは、メッセージを出して**既定値で続行する** (起動を止めない)。

### 2-2. `rshell` で断るときは EOT を返す (同 blocker 2)

`/api/cmd` は rshell にシリアルで流して **EOT (0x04) を待つ**。断りを空行と同じ `continue` で書くと
EOT が返らず、ホスト側は timeout まで待たされ**以後のコマンドが全滅する** (`POLICY_DEBUG.md` §4-7 と同じ壊れ方)。
規則: 赤字を 1 行出した後も `buz_off` → 1 tick 待ち → `serial_putchar(0x04)` を必ず通す。
行末までの読み捨ては `rshell.c:127` と同じ待ちで行う。

### 2-3. 網羅の要求

上の 22 件はレビュー 5 往復が積み上げたもの。実装の前に `userland/shell/` の**入力が通る固定長バッファを
1 度全部洗い**、「場所 / 上限 / 今の挙動 / 変更の有無」の表を `tools/tests/sh_truncation_tdd.md` に残す。
洗う対象: `char [N]` の宣言、`strncpy` / `kstrncpy` / `str_copy` / `strncat`、
