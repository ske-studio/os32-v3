## 3. 今日決まったこと (覆さないこと)

| 決裁 | 内容 |
|---|---|
| kstring | **x86 はアセンブリ維持**。C 版は他 32 ビットアーキ向け |
| 移植の対象 | **32 ビットのみ**。16/64 ビットは範囲外。64 ビット抽象化を足さない |
| メモリ配置 D1 | SHM 224KB / スタックを `0x2FC000` へ / 予算 468KB |
| メモリ配置 D2 | `KHEAP_BASE` は**浮かせたまま**、門はリンカの `ASSERT` |
| 次期カーネルの呼び方 | **v3** (2.0 が出荷済みなので「v2」と呼ばない。2026-09-15 の決裁) |
| v3 の順序 | **C11 → メモリマップ再配置 → ドライバの動的読み込み → PCI → Intel 82557** |
| 実機 | **当面使わない**。検証はエミュレータで十分 |
| 実機 LAN | **オンボードの Intel 82557**。LGY-98 は高価・品薄で取り下げ。**既存ドライバは消さない** |
| Trident | **保留**。NP21/W の実装が結線されておらず検証できない |
| GUI 契約 | 部品は**末尾追記のみ** (`WK_TEXTAREA` を追加、`WK_TEXTBOX` は不変) |
| エディタ | **機能は最低限**。取り消しも検索も要らない |
