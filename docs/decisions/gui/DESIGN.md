## 0. 前提の整理 (何が GUI の可否を決めるか)

**プロジェクトの意義と上限 (2026-09-04 ユーザ明言)**: このプロジェクトは過去の遺産である
PC-9801/9821 の実用性を証明するためのもの。目標は **Pentium 100MHz / 32MB で「超快適」に
動くこと**で、それ以上の性能を要する機能は PC-98 でやること自体がナンセンスと位置づける。
GUI の設計判断はすべてこの上限の内側で行い、下限は 386 で成立させる。

- **486 機能ティア (`cpu_features` / `-march=i486` / FPU 層) は見送り** (2026-09-04)。
  命令生成の差は数 % で、GUI の律速には効かない。
- `userland/lib/ui/` の microUI はテスト導入のみ。本採用ではない。

### 3.2 ウィンドウアクセラレータの資料上の仕様 (UNDOCUMENTED 9801/9821 Vol.2、`C:\WATCOM\docs\undocumented\io_wab.md`)

- 搭載チップは機種で異なる: S3 86C928 (Ap2/As2/An 内蔵、A-E01)、S3 Vision864 (Xs/Xp/Xn/Ap3/As3)、
  CL-GD5428 (Bp/Bs/Be/Bf/Ts/Np/Ns/Ne2/Nd/Es、PC-9801-96)、**CL-GD5430 (Xe/Cf/Cx/Cb/Cx2/Cb2/Xe10、
  PC-9801BX4)**、CL-GD5440 (Xa7e/Cx3/Cb3/V10/V7/Xb10)、MGA-II / MGA-2064W (X-B01/B03)、
  TGUI9680XGi (Xa16/Xa13/Xa12/Xa10/Xa9/Xa7/Xv13)、Cyber9320 (Ne3/Nd2/Na7/Nx/Lt2)。
- 制御は 2 段階 I/O: ボード型は **0FA2h (INDEX) / 0FA3h (DATA)**、内蔵型は **0FAAh / 0FABh**。
  レジスタ `00h` = ID 読み出し (内蔵: Xe=58h, Cb=59h, Cf=5Ah, **Xe10=5Bh**, Cb2=5Ch, Cx2=5Dh,
  Be 系=50h; ボード: PC-9801-96=60h など)、`01h`/`02h` = VRAM 窓 / MMIO 窓アドレス
  (80h=F20000h, A0h=F00000h, C0h=F40000h, E0h=F60000h; MMIO は F80000h〜F98000h)、
  **`03h` bit1 = 映像出力リレー (1 = アクセラレータ出力, 0 = 本体スルー)**、bit0 = MMIO 有効。
- PCI 機は **0FACh** bit1 (1 = 内蔵アクセラレータ, 0 = 98 グラフィック)、bit0 (RGB IN スルー)。
- 内蔵 GD5428/5430 の VGA レジスタは 0904h、0CA0h〜0CAFh、0DA4h/0DA5h/0DAAh、FF82h に
  写像される (PC-9801-96 は 0C50h〜0C5Fh、0D54h/0D55h/0D5Ah、0902h)。

- **40E1h / 42E1h / 46E8h / 51E1h / 5BE1h は Xe10 のポートではない** (2026-09-04 に訂正)。
  これらはメルコ WAB-S / WSN-A2F / WSN と I-O DATA GA-98NB という **C バス製ボード**の
  ポートで、NP21/W は機種 ID が 0x100 以上 (サードパーティ) か AUTO のときだけ登録する。
  C バス流の 16bit I/O デコードで、下位バイト E0h/E1h (+ジャンパオフセット) がボード選択、
  上位バイトが VGA レジスタ番号 (40E0h+n·100h → 3C0h+n、58E0h/59E0h → 3B4h/3B5h、
  54E0h/55E0h → 3D4h/3D5h、5AE0h → 3DAh)。奇数側 (xxE1h) がボード制御
  (40E1h bit0 = リレー、51E1h = ドライバのチェック値、5BE1h = VRAM 容量フラグ) で、
  値は「この値でないと Win95 ドライバがボードを認識しない」と試行で決めたもの
  (`cirrus_vga.c` のコメント)。
  Xe10 モードでは NP21/W も資料どおり 0FAAh/0FABh と 0904h / 0CA0h〜 / 0DA4h 系を
  使うので、**OS32 のドライバは資料のポートだけ実装すればよい**。
- NP21/W の `GD5430TYPE` の AUTO 値 (FFF7h〜FFFFh) は「Xe10 として起動し、サードパーティ
  ボードのドライバが探査ポートに触れた瞬間にそのボードへ化ける」実用機能
  (`cirrusvga_setAutoWABID`)。OS32 の検証では AUTO ではなく **明示的に 5Bh (Xe10)** を
  指定し、化けないようにする。

## 5. 表示の確認状況と残件

- 実機のアクセラレータでの表示リレー: 資料上は 0FA3h/0FABh レジスタ 03h bit1 または
  0FACh bit1 (§3.2)。NP21/W は内蔵 (0FABh 03h) と C バスボード (40E1h bit0) のリレー状態を
  OR で合成する「暫定やっつけ」実装だが、Xe10 モードで OS32 が触るのは 0FABh 側だけなので
  影響しない。

## 7. ドライバの書き方の指針

5. **CPU 直書きの原則 ([HW1]) は 98 標準グラフィックにだけ適用**: アクセラレータ系は
   チップの 2D エンジンを使ってよい (B3)。
6. **検証は同じテストで**: HAL 越しに同じ描画列を流し、screenshot (NP21/W) または実機の
   目視で全バックエンドが同じ絵になることを確認する。NP21/W で検証するときは
   `GD5430TYPE` を AUTO ではなく機種 ID に固定する (§3.2)。ai-debug の screenshot は
   WAB 対応済み。出力元の確認は TASKS の G5 の記録に従う。
7. **[V1]〜[V4] は通常どおり**: HostDrv 配備だけを検証と呼ばない、配備 yaml に載せる、
   失敗はそのまま報告する。
