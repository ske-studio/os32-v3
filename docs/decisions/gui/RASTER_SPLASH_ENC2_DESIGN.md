## 目的関数・共通規則
- 入力X[y,x,c]は既存 `resize_image` と同じ黒合成・縮小・中央配置後のRGB8整数。最適化中に画素を256色画像へ置換しない。
- 色q=0xRGB、展開E(q)=17(R,G,B)。距離d(a,q)=Σc(a[c]−E(q)[c])²。RGBの等重み・ガンマ符号値上で計算する。
- D(y,P)=Σx min_i d(X[y,x],P[i])。変更枠集合S(A,P)={i:A[i]≠P[i]}、m=|S|、O(A,P)=Σi,c[A[i,c]≠P[i,c]]+max(0,m−1)≤B。変更なしは0 OUT。
- 最初の番号は表示中に先行選択。番号自動進行なし。変更成分のみG/R/B順、以後の枠は番号OUTも数える。1成分×12枠なら23 OUT、3成分×12枠なら47 OUT。
- F(y,P)=Σ(k=0..L,y+k<H) a[k]D(y+k,P)、L=3、a=(8,4,2,1)。次3行にも同じPを当てる代理先読みであり、将来の変更列は展開しない。
- I_y(x)=argmin_i d(X[y,x],P[y,i])（ディザ前）。後述の時刻モデルの表示色R_y(x;A,P,π,I)で、E_y=Σx||X[y,x]−R_y(x)||²、Δ_y=E_y−D(y,P[y])とする。
- J(P,π)=Σy{F(y,P[y])+a[0]Δ_y}。当行項を実表示SSEで置換するので誤差の二重加算はなく、Δは負も許す。y=0は表示前に設定しΔ_0=0。
- 往復の更新は両隣のOUT制約を満たしJが厳密に減る時だけ採用。他行固定でもP[y]変更は次行の旧色・費用・表示誤差を変えるため、yとy+1のΔ・順序を再評価する。
- 同点は現状態保持。初回候補は(J,実OUT,枠順RGB444列,書換え番号列)の辞書順。最適性・B増加時の画質単調改善は保証しない。
- 配列は物理枠順を維持。候補色はRGB444昇順、画素は(y,x)昇順、距離同点は最小枠番号、木は最小ノードID。乱数・浮動小数点の縮約を使わない。
- 距離はint32、重み・和・SSE・比較はint64（乗算前に昇格）。PSNR表示のみ浮動小数点。重心は除算せず、色qの比較式 n||E(q)||²−2E(q)·s を使う。

## 段A: 256色マスター（ディザなし）
1. RGB8の同色画素を頻度hでまとめる（最大U=256000）。最初の中心はRGB444へ丸めた画素の頻度最大色、同点は色の小さい方。
2. 続く中心はRGB444の出現色から `頻度×既存中心までの最短距離` 最大を順に選ぶ。既選択色を除外し、同点は色の小さい方。不足時は最小色を複製し256要素にする。
3. 元のRGB8画素を最短距離の中心へ割当て、各クラスタの整数(n,s)からRGB444格子上の最小二乗重心へ更新。各成分を最寄り17刻みへ、ちょうど中間は低い方。
4. 空クラスタは中心を保持。重複中心は許す。SSEが減る更新だけ採用し、不変・非改善または20反復で停止。全体をRGB444、旧ID順に並べ直し最終割当て・頻度を再計算する。
5. マスターMは重複除去した色集合（≤256）。木用には256葉のIDと頻度を残す。Mは初期値・候補成分の出どころとし、行探索ではM外のRGB444も許す（後続のOUT予算のユーザー決定・PM決定F1を優先）。

## 段B: 256→128→64→32→16 の木
1. 葉代表はマスター色、質量は最終割当て画素数。各層で全対を `(代表間RGB8距離², 小ID, 大ID)` 順に並べ、未使用同士を順に組にする（最小完全マッチングではない）。
2. 親は子の質量・RGB8色和を合算し、その重心に最も近いMの色を代表にする。同点は小さい色、質量0なら子孫の最小色。親IDは子ID対の辞書順で付与する。
3. 同距離でも決定的に半数になる。4層後は16根の二分木の集合。RGB成分のビット切捨ては行わない。
4. 行yの候補は各根から子代表のF(y,[代表色])が小さい側へ4段降りた葉色。Fの同点は子ID。重複を除き最大16色、行の訪問順に依存せず前計算できる。
5. 木は初期値と交換候補の絞込みに使う。行交換は木候補の部分成分を使い、LloydはM全体由来の部分成分候補と部分重心を使うので、木候補外・M外にも移れる。木の貪欲枝選択には局所解の限界がある。

- 順序πは変更枠の置換、各枠の変更成分順はG/R/B固定。初期順は「当行でその番号を最初に使うx、番号」の昇順（未使用は640）。左端で使わない番号を後ろへ回す。
- 初期順と番号昇順を評価し、良い方から全位置対の入替を試す。最も表示SSEが減る1交換を採用して再走査、最大ORDER_PASSES回。候補同点は番号列辞書順、現状同点は保持。大域最適とはしない。
- はみ出し画素数K_y=Σx[R_y(x)≠E(P[y,I_y(x)])]（RGBどれかが古い画素を1回）。時間上の最大はみ出し幅max_j x_jも別記し、未使用番号による無害な遅延と区別する。
- この時間換算は線形近似。命令間隔・開始遅延・画素クロックとPIXEL0_OFFSET_NSは、カメラの左端の筋の幅から校正し設定版に記録。変更ありの行はt_last+IN_NS<LINE_NSを必須とし、等号以上を拒否する（0件行はemitなし）。既定では実OUT上限45となるためB=47も45以下で出力し、47本使えるとは保証しない。

## 段C: 各行16色、OUT制約・Lloyd・往復
1. 行0は16根の代表を色、根ID順に並べ、全枠自由の重み付きLloydを行う。初期16色は表示前設定なのでB制約外。
2. 初回y=1..399は前行P[y−1]の複製から開始。枠iの現在色pと木候補q、非空成分マスクm=1..7（bit0=R, bit1=G, bit2=B）から、qの指定成分だけpへ移した1枠交換を全列挙（同色候補は除き、重複色は統合）、O≤Bを満たす候補の順序と表示誤差を求め、Jの改善最大を採用する。初回の未計画の次行は評価せずF(y,P)+8Δ_yで選び、厳密改善なしまたはROW_MOVESで停止。
3. 同じ枠の再交換・前行色への復帰も許す。Sは各候補で前行との差から再計算し、枠数では打ち切らない。探索中の中間操作は出力せず最終差分だけを費用計算する。
4. 採用後のS外を固定し、S内を枠番号順に座標Lloyd更新する。全16枠への最近傍割当てで重み付き(n,s)を求め、各非空マスクごとに、現在色のマスク外成分を固定し、マスク内だけ重心を最寄り17刻みへ射影する（中間は低値）。Mの各色から同じマスク内成分を移す候補も加え、重複除去後に重心式の昇順で試す（同点は現色、次に小さい色）。
5. 各色提案をOUT制約と時刻モデル込みのJで検査し、最良の厳密改善だけ採用、次枠で再割当て。空クラスタ保持。最大ROW_ITERS周、不変なら終了。一斉更新による成分費用超過を許さない。
6. 部分交換・部分重心はM外のRGB444を許し、変更成分数は最終色と前行色の差から再計算する。マスクはその提案で動かす成分であり、行全体の変更成分を固定しない。1成分12枠=23 OUTを候補として表現できるが、12枠の採用や大域最適は保証しない。
7. 初回後、1往復を「399→0、0→399」とし最大2往復。各訪問は前行複製と現在解の2起点から手順2〜5。行0は根代表と現在解を起点に全枠Lloyd。最終3行は存在する先読みだけを使い重み再正規化なし。
8. 保存候補は両側O≤Bを満たすもののみ。現在解を必ず残す。次行の順序は現順と新しい初期順の両方から改善を試し、現順候補も評価に残す。採用時は次行順序も一緒に保存する。
9. Jが厳密に下がる候補のみ採用、1往復で変更0なら終了。配列の物理番号は再ソートしない。枠を並べただけでOUTが減るとは扱わない。

## 段D: 順序固定・時刻別表示色で誤差拡散1回
- 既存と同じFloyd–Steinberg、全行左→右（蛇行なし）。補正RGB=clip(X+累積誤差,0,255)、段Cで得たπを固定し、画素xにおけるR_y(x;i)の最近傍枠を選ぶ（行0はE(P[0,i])）。同点は小さい枠番号。
- 誤差e=補正RGB−R_y(x;i)を右へ7/16、左下3/16、下5/16、右下1/16。寄与ごとに0方向へ切捨ててから加算（負の `//` は不可）。画像外の寄与は捨てる。
- 下向きの誤差はRGB値として次行のバッファへ渡し、次行の時刻別表示色で量子化する。前行の色番号へ変換しない。クリップ分と丸め分の損失は既存と同じ仕様。
- 拡散後にπを変更しない。出力・指標のRとK_yは最終索引で再計算する。比較用に理想色E(P)で量子化・誤差拡散する版も保持し、同じP・πで評価する。計画時の代理Jと最終実表示指標を区別する。
- 256色で一度ディザした画像を再ディザしない。評価用の256色参照だけは独立に同じ拡散器で作成し、本経路への入力にはしない。

## 計算量・実装言語
- マスターはO((MASTER_ITERS+1)U×256)、最大約13.8億色距離評価。全B共通で1回。木はO(256² log256)、候補下降は≤400×128×2560画素距離評価。段A/Bはr1のまま。
- T≤2560、V=5、Q=4予算、R=32交換、2起点。部分マスク追加前の交換候補数≤QHV×2R×16×16=1.31億、基本SSEはO(T)、約3.36×10^11画素演算。F1で最大7倍（重複除去前）、約2.35×10^12へ増える。
- 順序評価の素朴上限は候補ごとO((2+ORDER_PASSES×120)W)、さらに次行分最大2倍。マスク追加前で約4.06×10^13、追加後は最大7倍の画素演算で、Pythonの全候補再描画は避ける。
- 固定索引の枠・成分別SSEをx方向に累積し、各成分の完了位置から区間和で順序費用を求める。1順序O(16×3)、接頭和作成O(W×3)。Python/Cとも同じ候補・同点規則を維持する。
- Lloydは最大QHV×2R×ROW_ITERSの呼出し枠組みで、各周16枠×最大7×(256+1)色提案を検査。早期停止・キャッシュで減るが秒数は保証しない。候補数・段別秒・RSSを計測する。
- Pythonは既存numpy/Pillowのみ、距離共有・ブロック化、最近傍/次点保持。int32距離ブロック約4MiB、SSE/int64接頭和。全画像×全候補×3成分テンソルは作らない。
- 拡散はQWH×16、約1638万距離評価。順序は段Cで確定する。Pythonは小fixture・一部行だけで照合・計測し、全画像・全4予算はS3のCで回す。
- 素朴順序項だけでも実効10^7/10^8画素演算毎秒でマスク追加前でも約47日/4.7日となる悲観上限（追加後は最大7倍）。接頭和実装後の実測でCの実行時間を報告し、測定前に実用速度を称さない。
- C化は同じ整数仕様のホスト実行ファイルへ。PNG読込・評価・v2直列化はPythonに残す。カーネルへ組込みなし、速度倍率の事前保証なし。

- 既定の比較出力は表CSV/MDと時刻モデルPNG 1枚だけ（4予算をB昇順に並べた1画像）。NPZ・ヒートマップ・理想復号/ディザなし/比較等の追加PNGは明示指定時のみ保存する。比較の中間配列は保存しない。
- 主対照は無変更optimize_rowへ同じBと既存行候補を渡す（N枠制限なし、band=1）。既存番号順と、同じ順序探索を適用した版の双方を示し、パレット改善と順序改善を分離する。旧obs_optimize_rowのN=1..16は歴史的参考のみ。
- 元画像SHA256・resize・RGB444・拡散を揃える。人物を主、平滑勾配・細線・行間急変・地球を補助とし、ディザ有/無・理想/時刻モデルを対にして測る。
- CSV/MD: 画像,B,方式,SSE,PSNR,ぼかしMSE,実変更枠数,実OUT（全399行の列・最大/平均）,K_y（各行・総数/最大）,はみ出し幅,秒,RSS,CRC。初期行除外、0 OUT行も集計。
- PSNR=10log10(255²/(SSE/(3WH)))、SSE=0は∞。ぼかしは原画/復号の双方へ分離[1,2,1]²/16、端は複製。整数未除算フィルタ差の二乗和/(256×3WH)をMSEとする。
- 採否は同一Bの時刻モデルのディザ後PSNR・ぼかしMSEが旧貪欲以上/以下を候補条件とし、理想画質・補助画像の悪化・実機写真をPMが合わせて評価する。良否が割れれば常用据置き、5/6 OUTへ自動切替しない。
- Iプレーン明暗対は既定OFF。追加実験ではkとk+8のRGB444色をR/G/B各成分で前者≤後者に制約し、初期根代表を最小SSEの実行可能対へ射影（同点は色列順、同色可）。探索でもこの制約を維持する。
- 対あり/なしを同一B・探索上限・拡散・順序で比較し、PSNR差・ぼかしMSE差・実OUT・K・時間を報告。I bitの組だけでOUTが減るとは扱わず、数値と実機評価が出るまで既定に入れない。
