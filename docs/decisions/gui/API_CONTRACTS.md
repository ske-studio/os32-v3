## G. 描画 (GDI 相当) — HAL のプリミティブと同じ粒度

### G8. パレットのリース — 確定 2026-09-04 (フォーカスのあるアプリに 14 色を貸す)

- **ウィンドウの外 (他のウィンドウ・デスクトップ) がリース中に色崩れするのは許容する**
  (ユーザ決定 2026-09-04)。フォーカスを失ったリース元のウィンドウもシステム色で表示される。
  気にするアプリは `Palette{active:false}` で代替色に描き直す。

- 全 16 色とラスタ効果 (走査線ごとのパレット切替) が要るゲームは**フルスクリーン占有**
  (ROADMAP) を使う。WM はその前後でパレット全体を退避・復元する。

## P. 性能規約 (386 で守る数値。DESIGN §8 の根拠)


### P2. 目標値と測定条件 — 2026-09-05 追加 (「P100 で超快適」を判定できるように)

カウンタ (G7) は回数と転送量、遅延は実機でしか測れない。両方に目標を置く。

| 代表操作 | 転送量の予算 (16 色、present バイト数。NP21/W で `gfx_stats` から) | 遅延の目標 (実機、入力 → 表示。10ms tick で計測) |
|---|---|---|
| テキストボックスに 1 文字 | ≤ 2KB (文字セル + カーソル) | P100: ≤ 2 tick / 386DX-20: ≤ 5 tick |
| ウィンドウのドラッグ (XOR 枠追従) | 枠 1 本 ≤ 1KB / 移動 | 枠が 1 tick 以内に追従 |
| ドロップ後の再描画 (露出分 + 移動先) | ≤ 移動したウィンドウの面積 × 2 | P100: ≤ 5 tick / 386: ≤ 15 tick |
| メニューを開く / 閉じる | ≤ 16KB (メニュー面積 + 露出) | P100: ≤ 2 tick |
| リストボックスのスクロール 1 行 | ≤ リスト面積 (転送で済ませ再描画しない) | P100: ≤ 2 tick |
| デスクトップ全再描画 | 128KB (全画面 1 回)。**切替時のみ**、操作の途中では禁止 | — |
| 1 周の syscall 数 | 3 (+ 状態変更分)、`gui_call` 合計 ≤ 10 / 周 | — |

出す。NP21/W では転送量だけを
判定し (ウェイト非再現)、遅延は実機 (P100 と 386 の 2 台) で年 1 回程度の実測に置く。
予算超過はゲート G2 / G3 の不合格条件。
