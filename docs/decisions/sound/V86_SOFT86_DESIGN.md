# PCM 専用機の V86 ゲストに提供する PC-9801-86 互換音源

状態は **草案**。対象は PC-98 の DOS ゲスト一セッション。着手時期は未定。[ROADMAP](../../ROADMAP.md) の将来項目と [U32](../../tasks/restructure/DECISIONS.md) に基づく。[AV 設計 §9](AV_HAL_DESIGN.md) のセッション・発音経路にボード PCM の再生を追加する。

## 起動時の選択

| 起動時に得た証拠 | V86 セッションの動作 |
|---|---|
| 0188h 系と 0288h 系がともに ABSENT、CS4231 の snd2 再生 backend が利用可能 | ソフト 86 の候補。begin で前景所有と stream を取得してから bitmap を切替。競合は BUSY として戻す。 |
| 実 86 または 26K | 搭載機のゲスト I/O と IRQ 配送を維持。26K を 86 として広告しない。 |
| 118 | 実 FM を素通しにし、118 の実 PCM を使える構成を保つ。実 FM と PCM の物理線共有は IRQ 設計の後段。両者の併用を実機受入に含める。 |
| probe 不明、出力なし、未対応機種 | 自動選択を見送り理由を記録。従来の V86 経路を使う。 |

IRQ 設計 S1 の保存判定を参照し、begin で再 probe しない。S2/S3 が物理線を所有する。双方 ABSENT でも BIOS の WSS INT5・DMA #1 と backend の open 成功を別々に確認する。probe 復元失敗時は物理 IRQ12 を抑止する。118 の初段は実 FM の反射と IRQ10 の PCM。後段は実配線を照合し、同線なら物理 IRQ12 を共有する。実 FM の bitmap 捕捉後も等価な実 I/O を一回だけ転送する。別線なら各線の所有者へ返す。

起動時に機種能力を固定し、各 begin では利用権だけを取り直す。CS4231 の物理線の到着回数は機種判定に使わない。

## ゲスト I/O と時間の所有

PC-98 の V86 monitor が SOFT セッションに限り TSS I/O bitmap の 0188h–018Fh、A460h–A46Eh を禁止側に設定する。#GP の IN/OUT では既存の観測・実ポート転送より先に対象を消費する。A462h/A464h は GS/73 用 DSP で、SOFT 86 は未搭載として FFh／書き捨てとする。発音の時刻、タイマ満了、FIFO 消費を同じ単調時刻で比較し、同時刻では期限を反映してから命令を処理する。

| 対象 | monitor が答える操作 |
|---|---|
| 0188h/018Ah、018Ch/018Eh | 各 bank の index を保持。data 書込みは時刻と通番を付ける。status とタイマは monitor で即答し、合成器に依存する data 読みは AV §9 の IOREAD で同じ命令に返す。奇数は FFh／書き捨て。 |
| A460h | AV §9 の ID と拡張許可を返す。許可解除時は bank 1 を隠す。 |
| A466h、A468h | FIFO 状態／音量、運転・停止・リセット・レート・割込み許可と要求を管理。 |
| A46Ah、A46Ch | 制御状態に応じて形式・左右の指定または割込み閾値を設定し、再生データを byte 順に受ける。 |
| 範囲内の未定義番地と A46Eh | 初版案は FFh／書き捨て。実測・資料で機能が判明した番地だけ仕様化する。 |

現行の v86_gp_emulate.inc は INS/OUTS 未対応で、a0_weak.c のセッション口は NOSYS。AV §9 の run/drain、幅 2/4 と同期読みは実装予定である。SOFT は幅 1/2/4 の IN/OUT・INS/OUTS を低位 byte から扱う。物理ポートを一つでも含む混在要素はアクセス前に未対応 fault とする。文字列は REP の有無、DF の両方向、16/32 bit のアドレスサイズに従い、一要素ずつ転送先／元の全 byte のメモリ権限とキュー容量を先に検査する。例外では完了要素だけ index・残数に反映する。

INS も通常の IN と同じく有効な影だけで即答する。同期読みは sid・命令・要素・byte 位置に応答を対応させ、副作用のある読み結果を保留する。再入時は保存結果から続け、全 byte の書き戻し後に要素を確定する。満杯時は未発行の要素から再開し、REP 全体が完了するまで EIP を保持する。fault/kill は実行停止・世代失効・期限解除を先行し、bitmap 復元を次の VM 進入前に保証する。stream・前景所有・保留応答は通常文脈で一回回収する。begin 途中失敗も取得済み資源だけ同じ手順で戻す。

## FIFO から CS4231 まで

仮想 FIFO は 32 KiB の byte リングとし、空／満、再生位置、閾値要求は monitor が所有する。経過時間×選択レートの整数剰余を保持し、完全な入力フレーム単位で消費する。停止中は進めず、形式やレート変更の直前に旧設定でその時刻まで進める。空なら無音とし残量を負にしない。満杯への書込み、閾値ちょうど、要求解除後の再発火、端数 byte の扱いは実 86 の短い I/O 列を基準に固定する。

monitor は消費した PCM と時刻付き FM イベントを順序付きでアプリに渡す。転送用キューとゲスト可視 FIFO は別に持ち、drain の頻度でゲストの残量を変えない。転送枠の不足は run の命令境界でアプリへ戻して解消し、音声の欠落を計数する。既存 v86s_fm_drain のイベントに PCM byte を一個ずつ詰めると syscall とキューを圧迫するため、PCM は時刻・形式・長さを持つ一括転送を提案する。公開 ABI の表現と採番は実装前レビュー事項。

V86 アプリが lib/os32_opna の整数合成、PCM の整数レート変換、libos32snd の加算・飽和、L3 pump を順に行い、一本の snd2 stream から CS4231 に出す。PC-98 のポート知識は monitor に置く。新規の合成・転送は通常文脈で行う。既存 HAL の DMA 補充コピーには AV §3-4 の上限を適用する。[合成器設計](SYNTH_OPNA_DESIGN.md)

FM 書込み・CSM・PCM 区間に共通の時刻と通番を割り当てる。PCM は次の制御イベント・閾値・リング端または 256 入力 frames で区切る。別口で drain しても、両列の確定済み時刻までを通番順（PCM は区間内の各標本時刻）に合成する。転送枠不足なら期限・端数・未転送 byte を保持して yield、次の run のゲスト I/O より先に未処理時刻を追う。追いつくまで新規命令を通さず、一回に最大一区間を処理する。周期数の計算とコピーは IRQ/IF=0 の外。FIFO 空による無音、合成済み位置への遅着、出力 underrun を別計数する。遅着分は内部状態を時刻順に進め、既出力標本を再送せず欠落 frames を記録する。正常受入は欠落ゼロ。

## IRQ12 の成立と配送

タイマ A/B の満了フラグと対応出力許可、FIFO の閾値要求と許可を個別に保持し、論理和で一つの仮想線を作る。ゲストの音源 ack は対応要因だけを消す。CS4231 の物理 PI は既存 handler が ack して snd2 を進める。PI 単独でゲスト pending を立てると、再生 period のたびに DOS の演奏が進むため、この組合せを負の試験にする。

AV §9-4/V0 に従い次期限に I20/I21 を arm する。PI と TI の同時 ack・再設定が再生と共存できなければ PIT one-shot の既存時計との共存を測る。両方失敗なら 100 Hz 制限をユーザー判断に戻す。物理 IRQ では起床印だけを立て、I/O のない VM も期限で通常文脈へ戻す。run 間の pump・IOREAD 待ちではゲスト時計を進め、前景停止では停止時刻まで確定して時計を凍結、再開時に期限を張り直す。満了ごとに予定時刻の CSM を同じ通番列へ積み、同時刻の OUT より先に処理する。満杯では未処理期限を保ち CSM を合流させない。27h の A/B フラグ許可・個別クリア、29h の出力許可を独立に試す。

実 FM 反射と SOFT は要求記録→候補選択→注入確定を共用する。現行 v86_pic_should_inject は片 IMR の検査で IRR/ISR を更新するので、この共通段で既存反射の呼出し元も移す。線の立上りを IRR にラッチし、音源 ack による入力解除でも未配送 IRR を保持する。確定後は両側の EOI が揃い、なお線が active なら一回再要求する。片側 EOI では重複させない。ICW2 変更後は slave の現ベース＋4 を使う。非 VM 時も IRR に保持する。VM 復帰で仮想 IF・STI shadow・両 IMR・優先順位・ISR を検査する。スタックとベクタの検査、フレーム更新の成功後にだけ IRR を消費し slave IR4 と master IR7 を in-service にする。既定ベクタは INT 14h。一復帰につき一件、同時の IRQ0 を先に通す。仮想 EOI とマスク解除で残存要求を再評価する。物理 EOI は既存 dispatch complete に一任する。[IRQ 設計「後段の実音源共有と仮想 PIC」](../../design/kernel/irq/irq.md)

## Ra266 の受入窓

初回の目標は整数 FM 6 声＋SSG 3 声＋ステレオ FIFO 一本を出力 44.1 kHz、period 256、lead 3 で 60 秒。これは未測定の目標。一区間は 5.80 ms、3 区間は 17.41 ms。17.41 ms は pump 間隔の上限、snd2 の cap 1024 frames は 23.22 ms。OUT 時刻、FIFO 消費、slice/drain、変換完了、staging 供給、played を同じ窓で採る。実データに孤立クリックを入れ、OUT 時の外部マーカーとライン出力を同時収録して計算値と照合する。PCM の OUT→出力には先行 FIFO の待ちが入り、消費→出力と分ける。暫定合格は後者と FM 書込み→出力が 1 pump 窓＋cap（40.63 ms）以内、前者はこれに先行 frames／入力レートを加えた値以内。22.05 kHz では同じフレーム数で各時間枠は倍になる。

タイマ周期 T ごとに予定→検出、検出→注入可能な VM 復帰、復帰→注入を別記し、IF/IMR 保留も計数する。暫定予算は検出最大 min(T/4, 1 ms)、配送可能時の検出→注入最大 T/2。短周期で超過したらその周期を対応外として報告する。60 秒窓の演奏速度誤差は暫定 1% 以内、CSM の欠落ゼロ。ゲスト側の意図的保留は配送予算の集計から分ける。

PII 266 MHz で声数 1→3→6、SSG、FIFO、リズムを順に加え、各 period の trap・合成・pump cycles と各最大値、staging の供給時刻が HAL の補充期限に間に合ったかを記録する。欠音・期限超過ゼロ、pump 最大 768 frames、IRQ0 最大 200 µs、対象 HAL の IF=0 最大 1450 µs を要求する。既知波形で 8/16 bit の符号・byte 順、左右単独／両側、レート変更境界の位相継続を照合し、広い整数の加算後に一度だけ飽和した標本と一致させる。44.1 kHz 未達ならゲスト速度を保って 22.05 kHz で再測する。

## 依存順と先に赤にする検査

| 段（製品行数の概算） | 入口で検証する差分 |
|---|---|
| V0 資料・実線測定 | 下記の未照合欄を埋める。I/O なし短周期、PI 単独、TI＋PI 同時で期限と要因を比較する。 |
| 共通 IRQ/PIC（200–350） | 実 FM 反射と仮想要求で両 IMR、STI shadow、ICW2、片側 EOI、別要因残存、stack fault 時の IRR/ISR 不変を検査。 |
| Q1/V1/V4 → V2/V3/V5（800–1200） | FM 列、期限、捕捉とセッション四口を結線。幅・REP 両方向・ページ跨ぎ例外・満杯・同期 INS で読み副作用と OUT が一回。世代を跨ぐ reply を拒否。 |
| ボード FIFO（200–350） | 閾値前後、満杯、部分 frame、折返し、停止とレート変更を偽時計で再生。drain 頻度を変えて残量と IRQ 列を比較。 |
| PCM 一括転送 ABI（150–300） | 末尾追加・生成・C89 検査・clean/all。別列同時刻と満杯再試行で通番・標本を比較。順序反転、二重消費、旧 sid 許可を変異にする。 |
| V6/V8 → IL（250–400＋実機窓） | 機種選択で実機の SOFT 用 bitmap 差分ゼロ。118 の実 FM＋PCM 同時、PI 単独、別線 FM/FIFO と DOS 演奏速度を測る。Ra266 は上記の実出力窓で判定。 |

各段で失敗入力を先に登録し、条件反転・早すぎる注入確定・期限取り違えなど対応する変異を通す。AV §9 の構文は将来契約であり、合成ライブラリの存在だけでは run/drain の受入は成立しない。

## ユーザー確認

対象 DOS ソフトごとに再生専用で足りるか、入力→発音の許容 ms、必要な最短タイマ周期と許容誤差を確認する。V0 の両起床源が成立しない場合の 100 Hz 制限、Ra266 未達時のレート・声数も判断を求める。118 の実 PCM 利用は既定要件である。
