# P6 — CI を一から作る (U1・U2・U9・U10。小さく始めて育てる)

> 上位: [TASK_RESTRUCTURE.md](TASK_RESTRUCTURE.md)・[RULES.md](RULES.md) (入口と、どの段も先に読む決まり)

始める前に PM が TASK_CI_REWORK の状態行を「残りはこの票の P6 に移した」に直す (二重に持たない)。古い workflow と古い入口 (`tools/checks/run.py`・`tools/ci/gate.py`) は直さない — 移動 (P3) の変更で止め、P7 で消す。新しい CI は別のファイルに一から書き、回すのは新しい検査だけ。形は U2: 途中の push は変更に関係する検査、main に入れる SHA は全件を変異込み。設計は `docs/design/tools/ci/ci_v2.md` (P1-7a)。

## 文書だけの取り込みの起動の記録 (U21、2026-11-26)

P6 の切り替えまで、文書だけの取り込みも PC-98 (pc98emu) と PowerPC (QEMU) の起動の記録をその SHA で取る。媒体はカーネルのコミットの短い SHA (`tools/gen_build_id.py` の OS32_BUILD_COMMIT、無ければ HEAD) を埋めるので、前の記録の引き継ぎ (U18、`land_gate.py` の口) は成り立たない。切り替えで、埋める値を製品の入力から決まる値にするかを決める (変えると生成物が変わる)。
