### P2-2 の記録

- Rust の release ビルドは Cargo の `trim-paths` でソース位置を正規化する。木内のターゲットクレートのシンボル識別子には、パッケージ名・版・ターゲット・有効な cfg を使う。Cargo のキャッシュ名は Cargo が決める。
- 2 木の全体比較で見つかった ar メンバーの時刻は GNU ar の決定的モードで固定する。インストール ISO は `SOURCE_DATE_EPOCH` (既定 946684800) を使い、 xorriso でボリュームとファイルの日時を固定する。
- 世代表のリンク入力は木内を相対パスで記録し、Rust メンバー名のうち Cargo のキャッシュ接尾辞を外す。リンク時の検証と個別の入力記録には完全なメンバー名を残す。
- `rust-build-paths` は製品の GUI ELF に作業木と sysroot のパスが残っていないこと、別々の木で組んだ事例のバイト一致、パスとシンボル識別子の各変異を検査する。
- 受入のログは作業領域 `~/os32-tmp/run/restructure/p2-2/tmp/` の `identity.log`。x86 の比較に追加の除外はない。
