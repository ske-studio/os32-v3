## 票の完了の基準 (全文)

(1) 追跡ファイルのうち所有の表に行の無い物が 0 (検査 `src-owner` が CI で通る)、(2) 最上位にカーネルのソースの置き場が `sys/` の 1 つだけ (`kernel/`・`mm/`・`exec/`・`init/`・`arch/`・`platform/`・`drivers/`・`hwdev/`・`fs/`・`gfx/`・`sound/`・`input/`・`net/`・`kapi/`・`include/` が最上位に 0)、(3) 検査の本体が `tests/` の下にあり `tools/tests/`・`tools/checks/`・`tools/accept/` が 0 ファイル、(4) workflow の YAML に検査の名前とソースのパスの列挙が 0 行、(5) 結果の表に SKIP の状態が 0 で 7 つの状態 (仕様 §14) だけ、(6) 移行の各波で生成物の一致の記録がある (一致しない波は `Sep-Changes:` の宣言とレビューの記録)、(7) 置き換えの前後で回る検査の名前の集合の差が、ユーザーが承認した統廃合の表と一致、(8) CI の所要と検査の数の前後の比較が [gate.md](../../design/tools/ci/gate.md) にある。8 つを満たした SHA が main に在る。
