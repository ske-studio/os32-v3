# P8 — 中身の責務の分け直し (この票では候補を挙げるだけ)

> 上位: [TASK_RESTRUCTURE.md](TASK_RESTRUCTURE.md)・[RULES.md](RULES.md) (入口と、どの段も先に読む決まり)

移すだけでは済まなかった物を、P0-6・P1-3・移動 (P3) で 1 行ずつこの表に足す。1 行 = 後で 1 本の票 (設計の往復から)。この票の完了には数えない。

| 候補 | なぜ移すだけでは済まないか | 出所 |
|---|---|---|
| 共通が装置の名前の関数をリンクで呼ぶ所を HAL の口に | 呼ぶ側の書き換えが要る ([check_layers](../../design/tools/check_layers.md) §8 の末尾) | TASK_PPC_SEP の残件 |
| 入力のキーの値を機種に依らない OS32 のキーコードに作り直す (今は `sys/include/kbd.h` の `KEY_*` が PC-98 のスキャンコードそのもので、共通の入力の HAL `sys/hal/input/in2_excl.c` が `KEY_STOP`・`KEY_CTRL`・`KEY_GRPH`・`KEY_TAB` を直に使う。PowerMac は PC-98 の値に訳して入れている) | 入力の全部・GUI・機種ごとの訳に及ぶ中身の変更。移動では今の値を「OS32 の共通のキーの値 (由来は PC-98)」として残す | A1 の 4-2 (sol の P1-3 の P2)、ユーザー 2026-11-26「残す ただし、リファクタリング対象として記録して」 |
| `tools/gen_opna_layout.py` の生成と「古いか」の確かめを分ける (今は 1 本が、`--write` でヘッダ `lib/os32_opna/opna_layout.h` を作り、既定では作った物とコミット済みのヘッダを比べて違えば非 0 で製品のビルド `make opna-staticlib` を止める — 生成器と検査が 1 本に混ざっている) | 呼び出しの形と `build/os32snd.mk` の規則を変える中身の変更。移動では運用の道具として `tools/` に残す | A1 の 4-1 (sol の P1-0 の P2)、ユーザー 2026-11-26「これもリファクタリング対象として記録」 |
| HWDEV 契約のヘッダ順を配置から独立させる | 生成器が入力パスを辞書順に並べてから契約 CRC を計算する。P3 の移動で順が変わり、旧順でのみ基点の CRC を再現した。 | P3 の停止記録、gen_hwdev_contract.py の generate |
| ペアモジュールの ABI 世代値をヘッダの置き場から独立させる | gen_sqlite_imports.py が契約ヘッダのコメントと相対 include の綴りもハッシュに入れる。P3 では CD ほか 10 部品で世代値が変化。CD は旧本文だけを戻すと基点の 0x25bf6e75 を再現した。 | P3、PM の機械の module-abi.log |
