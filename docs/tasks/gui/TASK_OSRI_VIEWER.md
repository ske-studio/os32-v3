# TASK_OSRI_VIEWER — .osri ビューアー (ユーザーアプリ)

> 状態: **設計中 (2026-11-04)** — 設計は確定し、実装は GeForce の後で待つ。詳細設計は [OSRI_VIEWER_DESIGN](../../decisions/gui/OSRI_VIEWER_DESIGN.md)。段はまだ出さない。前提のラスタの常用の再生は票 TASK_RASTER_SPLASH の S5。

## 0. ユーザーの決定 (2026-11-04、原文)

- 「ユーザーアプリとしてビューアーを用意しようと思います。その場合SDKの状態と現在の独自画像形式の実装方法を確認して設計しましょう。」
- 「これをユーザーランドアプリ化するのはGeForceのあとです。」「が、計画書と詳細ドキュメントは用意しておきましょう。」
- 行ごとに色を書き換える画像の表示時間: 「既定１．任意で２分まで表示。何らかのキー入力で延長。VSYNCまでキー入力はバッファで受けて良い。」「さっきの１，案を既定に。キー入力で既定時間延長」「キー入力があればいつまでも延長。」— 既定 30 秒、起動の引数で 2 分まで、Esc 以外のキーで締切を「最後のキーから 30 秒」に延ばす (合計の上限なし、PM の読み — キーごとに積み上げない)、Esc で即終了、可視区間中のキーは buffer にためて VSYNC で読む。色を書き換えない固定の画像は Esc まで。

## 1. 要約 (全文は詳細設計)

| 項目 | 決めたこと |
|---|---|
| 方式 | 再生はカーネルに任せる KAPI を 1 つ足す (`gfx_osri_show(path, duration_ms)`)。S5 の再生の核を HAL の中で共有し、二重に書かない |
| 画面の所有 | 既存の門 (`gfx_init` → `appslot_gfx_claim` → `gfx_shutdown`)。アプリは `mkos32x --gfx` で、`gfx_init` の後に show。GUI 中だけ呼び手 == 所有者を照合、CUI は gfx 開始済みだけ |
| 表示経路 | HAL の hook `osri_show`。pc98 GDC 640×400 planar4 の 31k/24k が対応、GeForce・PEGC480・200 ラインは NOSYS |
| 断る場面 | シリアルの /host (sfs) セッション中・PCM 再生中は BUSY。LAN の取りこぼしは許す |
| 誤りの値 | 既存の OS32_ERR_* (INVAL・NOTFOUND・IO・NOSPC・NOSYS・BUSY・AGAIN) |
| KAPI の版 | GeForce の後に実装するときに取り直す ([ABI]) |

段の分け方・受入・ファイル割当ては詳細設計の §5・§7。
