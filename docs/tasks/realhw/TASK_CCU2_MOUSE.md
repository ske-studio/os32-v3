# TASK_CCU2_MOUSE — 2nd CCU (2 本目のシリアル) でシリアルマウスを使う

> 上位: [実機の票の索引](PLAN.md)

> 状態: **計画 (2026-10-28)** — 資料集めまで済んだ。**実装するものが無いときの余暇でやる** (ユーザー 2026-10-28)。手元のマウスは 2 つとも PS/2 専用の見込みで、受け身の変換アダプタでは動かない見込み — マウスの用意 (両方式のマウス・シリアルマウス・能動の変換器のどれか) が先。

## 0. ユーザーの依頼 (2026-10-28)

「pc98bibleとundocumentedを調べてほしいのですが、2nd ccuについてです。これはバスマウスが使用できるという話を聞き現在Dsub9の端子にPS/2のマウスを変換アダプタ経由で接続しています。OS32で使用するための資料を集めてください。」

## 1. 調べの結果 (sol、2026-10-28、全文 `~/os32-tmp/run/ccu2/REPORT.md`)

- **2nd CCU は RS-232C のシリアルポート** (PC-98 のバスマウスの回路とは別物)。コントローラは 16550 相当 (8251 互換ではない)、FIFO あり。資料: UNDOCUMENTED `io_2ndrs.md` (Bible と食い違えば UNDOCUMENTED)。
- 番地は既定で **0238h〜023Fh** (RBR/THR・IER・IIR/FCR・LCR・MCR・LSR・MSR・SCR、DLAB で DLL/DLM)、割込みは **INT1 = IRQ5 (マスタの PIC の 5 番)**。NEC の Ra266 の仕様表と割込みの表で、シリアル 2 系統 (25 ピン・9 ピン) と「2nd CCU = IRQ5、セットアップで無効にできる」を確認。
- ボーレートは 1.8432MHz 系 (1200bps は分周 0060h)。7N1 は LCR=02h (UNDOCUMENTED の LCR の表は 6/7bit の符号が逆 — 16550D のデータシートと BSD を採る)。
- 搭載の情報は BIOS の F8E8:0011h bit3 (物理 F8E91h、1=あり)。有効状態・外の端子・マウスの検出までは保証しない。
- **IRQ5 の衝突に注意**: 基準構成 ([RA266](../../decisions/realhw/RA266.md) §1-1) では増設の HighPoint (0:12.0) が IRQ5。有効にする前に BIOS の設定か配線を確かめる。
- Dsub9 の端子は標準の PC の DTE の配線の見込み (DTR=4・RTS=7 が出る — シリアルマウスはここから給電)。Ra266 固有の端子図は未確認。
- マウスの形式: Microsoft (1200bps・7N1・3 バイト、DTR=1 のまま RTS を立てて 'M' を返す) と Mouse Systems (1200bps・8N2・5 バイト)。
- **受け身の変換アダプタ (PS/2 ↔ D-sub 9) は、マウス自体が PS/2 とシリアルの両方式 (コンボ) でないと動かない** (Tripp Lite の仕様書、X.Org の mouse の説明、FreeBSD moused.8:431-438)。PS/2 専用のマウスには能動の変換器 (マイコンで方式を変換し外から給電) が要る。
- 「バスマウスが使える」という話は、2nd CCU (シリアル) と PC-98 本体のバスマウスの端子の取り違えの可能性 (推測)。

## 2. 手元の機材 (ユーザーの写真、2026-10-28)

| 機材 | 型番 | 見込み |
|---|---|---|
| IBM のマウス (プラグはグレー) | MODEL 13H6690、ASM P/N 06H4590、FRU 06H4595、FCC ID DZL210429 (DZL = Logitech) | **PS/2 専用の可能性が高い** — IBM 自身の互換表が「IBM PS/2 Mouse」と呼ぶ、販売の記載も PS/2 (Mini-DIN 6-pin) のみ。両方式でないことをメーカーの仕様で直接示す資料は無く、FCC の登録の中身 (fccid.io) は 403 で見られなかった |

確定させる方法: 2nd CCU のドライバができたら、RTS を立てて 'M' が返るかを見る (返れば両方式、返らなければ PS/2 専用) — ドライバの最初の受入の項目にする。

## 3. 手本 ([HW3]、BSD の実装)

- FreeBSD releng/4.11 bd1be22e `sys/pc98/pc98/sio.c` — 2nd CCU を base 0238h・IRQ5 の 16550 として扱う (`sys/pc98/conf/GENERIC:174`、`sio.c:132,769-793` の分類、`1324・1432・1546` の OUT2 と IER、`3525-3608` の LCR・FIFO・分周、`2844-2989` の受信)。**ハードの扱いの手本**。
- FreeBSD releng/5.5 d4c364b3 `usr.sbin/moused/moused.c` — Microsoft 形式と Mouse Systems 形式の起動 (`2656-2685` の RTS と 'M' の識別) と復号 (`1690` 以降・`1850-1894`)。**シリアルマウスの復号の手本**。
- NetBSD netbsd-10 `sys/dev/ic/com.c` — 共有の IRQ で要因の無いときの扱い (補助)。PC-98 の 2nd CCU 固有の実装は見つからなかった。
- NP21/W は 2nd CCU を実装していない (`src/bios/bios.c:363` で搭載の bit を 0、`src/io/serial.c:918-936` は 1st CCU だけ) — エミュレータでは試せない。

## 4. OS32 での作り (案、設計の往復はまだ)

- 今の `drivers/char/serial.c` は 1st CCU (8251 互換・IRQ4) 用 — 2nd は別のドライバ (16550、受信だけ、TX の割込み不要)。
- 割込みは `kernel/irq/irq.c` の `irq_register()` で IRQ5 に。ISR は受信のバイトを輪に入れ、協調の側で復号。
- 入力の口は `kernel/input_service.c` の PointerOps (今のバスマウスの `mouse_poll` と同じ形、`platform/pc98/d2_bind.c`)。KAPI は変えない。バスマウスとの同時使用は選択か合成の設計が要る (`drivers/input/mouse.c` は単一のモード)。
