# サウンド・入力の HAL (DirectSound・XInput 相当の土台)

> 状態: **設計中 (2026-11-09)** — 設計は確定・ユーザー承認済み ([AV_HAL_DESIGN](../../decisions/sound/AV_HAL_DESIGN.md))、実装を待つ。前提は HAL v2 の A0 (ユーザーの確認待ち) と、音の段は 1kHz tick の段 B の合格。PM は設計に専念中のため実装の着手はユーザーの解除の後。

## 0. ユーザー決定 (原文)
決定の全文の原文は確定設計の冒頭が参照する記録 (~/os32-tmp/run/hal-av/DECISIONS.md) にある。主なもの:
- 「一つのアプリが占有する作りで大丈夫です。」「これはシングルタスク」/「1khz tickの実装前提」
- 「synthの置き場は変更して構いません。出来るだけシンプルにするのでHAL側に寄せるほうが良いです。ただ、カーネルに直にミキサーを実装するのは反対です。」
- 「入力に関しては現代のデバイスのほとんどがXinputなのでこれをベースに考えてdirectx世代に互換ラッパーを用意するほうが良いと思います。」
- 「MMLを一旦廃止にしても良い」/「V86側を変更して対処」/「libos32sndを廃止して新しい仕組みで統合」
- 「カーネルのサウンド要件にFM音源やPSG音源の口がない。ネイティブ側にあればこちらを使う様にしたい。」/「ハードウェアより上位を求められればソフトウェアにするか未対応扱いにするかはユーザーの判断で変えられるように。…」
- 承認 (2026-11-09):「その他はOK」— ミキサはカーネルと HAL の間の層として明記 (追記 3)、MML の KAPI 10 欄は「v3の最後のKAPIの整理時の削除対象」、game は「開発中なので無視でいいです」。

## 1. 詳細設計 (確定) の要約
全文は [AV_HAL_DESIGN](../../decisions/sound/AV_HAL_DESIGN.md)。
- カーネル: 装置の一覧と能力の表・PCM 1 本・位置・DSP の口・FM/PSG チップの口 (追記 2)・前景・入力 (raw 128・独占・パッド 4 台・1ms)。ミキサ無し。
- HAL ライブラリ libos32snd (userland/lib/snd、旧 libos32snd を置き換え): ミキサ (カーネルの流れの唯一の書き手)・voice・ソフトの FM 合成器・MIDI・本物/ソフトの選び方 (SOFT・FALLDOWN・FAIL)。
- 段: HAL v2 A0 → AV0 (宣言と MML の廃止) → 入力の段 → 1kHz tick 段 B → 音の段 (S・C) → 合成器の照らし直し → L・V → USB 段 1 の後に P。約 8,600 行。
