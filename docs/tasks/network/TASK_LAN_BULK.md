## 1. 詳細設計 (確定) の要約
- link (EtherType 0x88B5) に OPEN/OPENED/BULK_DATA/BULK_ACK/CLOSE/CLOSED/PROBE と FS_META/FS_RESULT を足す。本文 1024B、32bit のビットマップの選択再送、grant は転送全体の通し番号の右端、OPEN は VFS 呼び出し 1 回、1 フレームで足りる転送は OPENED にデータを載せる。
- 律速は受信の枠: x86 の SW RX を 4 枠から「16〜22 + 制御 1」へ広げる段を持つ。PowerMac の GEM は枠を増やせるかを資料で確かめ、増やせない間は出た値を記録する。
- link の処理は IRQ0 から前景へ移す (FG が 10 jiffy 回さなければ IRQ0 が 1 回救う)。/host の待ちは NIC の下半分と受信を直接回し HLT しない。
- 段の表は設計の §8、受入は §9、実機の測定の計画 (先に測る道具) は §7。
