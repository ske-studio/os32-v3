## 第4部 割り込みシステム

### §4-1 IDT構成

| ベクタ | 種別 | 用途 |
|--------|------|------|
| 0x00-0x1F | 例外 | CPU例外 (除算エラー, GPF等) |
| 0x20 | IRQ0 | PIT タイマ (100Hz) |
| 0x21 | IRQ1 | キーボード |
| 0x22-0x27 | IRQ2-7 | マスタPIC (0x27=カスケード) |
| 0x28-0x2F | IRQ8-15 | スレーブPIC |

### §4-2 PIC (8259A) 設定

PC-98のPICはPC/ATと異なるポートアドレスとカスケード構成を持つ。

| 項目 | マスタ | スレーブ |
|------|--------|---------|
| コマンドポート | 0x00 | 0x08 |
| データポート | 0x02 | 0x0A |
| ICW3 (カスケード) | 0x80 (IR7) | 0x07 |
| ICW4 | 0x1D (BUF+SFNM) | 0x09 (BUF) |
| ベクタオフセット | 0x20 | 0x28 |

### §4-4 割り込みの動的登録と `irq_dispatch` の約束

実体は `kernel/irq.c` / `kernel/irq.h` / `kernel/irq_math.c` (定数は `kernel/irq_math.h`)。

- **登録できる線**は共通スタブに結んだ 3/5/6/8/9/10/14/15 だけ。固定スタブの線 (0/1/2/4/7/11/12/13) は `IRQ_ERR_NOTSUP` で断る。
- **共有**: 2 つ目以降の登録は、既存の全登録者と新規の両方が `IRQ_F_SHARED` のときだけ受ける。1 線あたり最大 4 登録 (`IRQ_MAX_HANDLERS`)。PIC のマスクは登録数で持つ (最初の登録で開け、最後の解除で閉じる)。共有者は自分で `irq_disable` を呼ばない。
- **`irq_dispatch(irq)` は割り込み文脈で IF=0・ネスト無し**で走る。全登録者を順に呼び、最初の `IRQ_HANDLED` で打ち切らない。1 巡目で誰かが受けたら同じ走査をもう 1 回だけ行い、結果は 2 巡の OR。そのあと `irq_finish` が EOI を 1 回送る (動的経路で `pic_eoi` を呼ぶのはここだけ。IRQ15 はスレーブの ISR を読んでスプリアスならマスタにだけ EOI)。
- **ハンドラの約束** (この層は検査しない。レビューと受入で担保する): 有界であること (装置待ちのスピン禁止)。要因を落としてから `IRQ_HANDLED` を返す (8259 はエッジ設定なので、落とさないと次のエッジが来ない)。予算を超えたら装置側の割り込みをマスクしたまま `IRQ_DEFERRED` を返し、自分の tick フックで残りを回収してマスクを外す。**SHARED か排他かを問わず、全登録者が IRQ に頼らない定期回収 (tick フック) を持つ** (共有線のエッジ喪失は有限の走査では防げない — IRQ は加速器、tick が保証)。
- **ストーム**: 1 tick に同じ線で誰も受けないディスパッチが 200 回 (`IRQ_STORM_LIMIT`) を超えたら、その線をマスクして 1 回だけ報告する。次の登録・解除の再計算で解ける。`irq_quarantine_line` の隔離は再計算では解けない (sticky)。
- **IF=0 区間の上限**: システム全体で IF=0 の区間は 1 tick (10ms) 未満に収める。2 回以上の tick 境界を IF=0 で跨ぐと IRQ0 が 1 つ落ち、`tick_count` と `sys_time_now` が 10ms 遅れる (検出はしない、[KAPI_SPEC の µs 時計](KAPI_SPEC.md#µs-時計-v59))。IRQ 文脈から呼ばれる処理は 1 回の呼び出しの所要時間をこの内側に収める。
- **寿命**: ISR の中からの登録・解除は `IRQ_ERR_CTX` で断る。表の更新は `irq_save` の中で行い、`{fn, arg, flags}` は fn を最後に書いて一括で有効にする。解除の順は「装置の要因を止める → `irq_unregister` → 状態を解放」。`irq_unregister` が戻った後に callback は走らない (単一 CPU)。
- **未実装**: debug ビルドのハンドラ 1ms 超の報告と IF=0 区間の最大値の計測。
