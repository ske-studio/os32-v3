# os32-test-basis — 試験の出所と、固定の外し方

決まりの正典: 試験の期待は設計から ([POLICY_DEV](../../../docs/POLICY_DEV.md) §6)、検査の宣言の形は `tools/checks/run.py` の docstring、試験の一覧の読み方は [TESTS](../../../docs/TESTS.md)。関門は全部の検査を変異込みで回す ([POLICY_CI](../../../docs/POLICY_CI.md) G1)。

## 1. 検査の宣言 (`tools/checks/<名>.py`)

```python
CHECK = dict(name='<名>', tier=1, needs=[], budget=<秒>,
    covers=['<読むファイル・glob…>'],          # 試験が読む入力を全部
    basis=['docs/design/<パス>.md <節>'],       # 期待の出所。現行の文書だけ
)
```

- `basis` は現行の設計書・仕様の節を指す。アーカイブの文書・実在しないパスは `python3 -B tools/checks/run.py --lint` が止める。出所が無ければ、先に設計書に契約を書く (スキル os32-archive の §2 の書き方)。
- 設計から期待を導けず、今の振る舞いを写しただけの試験は `kind='characterization'` と書く (振る舞いが変われば期待も変える試験だと分かるように)。
- `covers` の漏れは lint の `uncovered input <パス>` で分かる。足す。

## 2. 固定の型と、替え方

試験がソースの形に結び付いていると、正しい直しのたびに落ち、固定先を書き換える作業になる。

| 固定の型 | 何が起きるか | 替え方 |
|---|---|---|
| 定義・生成物のハッシュの固定 (`sdk/kapi.json` の sha256 など) | 無関係な 1 行の追加で落ちる | 守りたい性質を直接見る。ABI は基点 (`origin/main` との merge-base) との比較 `tools/check_kapi_abi.py` (末尾追加だけを許す。壊す時は本文に `KAPI-Break: <理由>`) |
| ソースを特定のコミットとバイトで比べる (`git show <SHA>:<path>`) | そのファイルを直すたびに SHA を書き換える | 段の受入のための固定なら、段が済んだら外す。生成物が変わらない事は分離の枝の `sep` の identity が見る |
| 古い版のソースを手本にした差分の試験 (旧実装と新実装の出力を比べる) | 旧実装が履歴に在る限り有効 | そのままでよい。CI は履歴を全部取る (`fetch-depth: 0`) |
| 件数・行の並びの固定 (`len(table) == 11`) | 表に 1 行足すと落ちる | 件数でなく中身を見る (要る名前が全部在る・余計な名前が無い)。件数に意味がある時 (枠の上限との余裕) は、その理由を試験の文に書く |
| 変異の目印 (置き換える元の式の文字列) | 式を書き換えると「mutation point changed」で落ちる。`MUTATE=0` では見つからない | 触った試験は `MUTATE=1` で 1 回回す。目印を新しい式に合わせ、RED の数が前と同じ事を見る |

## 3. 変異込みでしか見えない赤

2026-11-18 に関門を変異込みへ切り替えて、初めて見えた物:

- 変異の時だけ作る写しの木に、足したヘッダ・ディレクトリが入っていない (`kcg-file-host`)。
- 置き場を移したソースが検査の走査の根から外れ、違反を差し込んでも検出しない (`p2v` と `tools/source_roots.py`)。
- 変異の試験だけが使う道具がジョブに無い (`ppc-compile` と QEMU)。
- 古い目印 (もう無い式を置き換えようとする変異)。

直した後の確かめ: `MUTATE=1 make check-<名>` が rc=0 で、ログの `RED` の行が変異の数だけ出ていること。

## 4. 試験の覚え (`tools/tests/<名>_tdd.md`)

覚えは記録の層。頭の `票:`・`契約の正典は` の行は、現行の設計書のパスと節を指す (アーカイブの票を新しく指さない — `make check-archive-refs` が件数の増加を止める)。本文が今のコードと違ってきたら、今の形に直すか、当時の記録である旨を頭に 1 行で書く。
